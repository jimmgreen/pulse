测试入口全部拿掉

「选择组件包文件夹」「选择应用」「使用 Pulse 启动」「刷新状态」、会话列表和逐个「停用」都只在测试时有用。组件随 Pulse 安装，分开的「启用 / 停用自动接入」合并成一个开关。

开启前讲清范围

一张示意图加两句话：哪些软件会改用 Pulse 窗口，哪些仍是 Windows 窗口。下面四条须知讲清重新打开软件、影响范围和怎么恢复。打开开关时再确认一次，开启后这些内容收起。

问题有下一步

入口被其他软件占用、Windows 拒绝改动，都写明发生了什么、Pulse 没有动什么，并给出重试或导出日志。文件夹入口被改回时沿用现有的「恢复」和「全部改回资源管理器」。

更安静的版面

文件夹入口回到勾选列表，附加说明并成一行浅色小字；页首三张状态卡点一下就跳到对应设置；页尾「全部恢复 Windows 默认」一次交还所有替代，开机和托盘设置不变。

落地改动：page 11 的布局在 settings_layout_sections.h，绘制在 ui_settings_core.cpp。对话框分区只保留 DialogManagementController 的 EnableAuto / DisableAuto / Refresh，去掉 SelectBundle、SelectApplication、Launch、Disable 的界面入口，组件包路径改由安装目录决定；ThirdPartyDialogs* 测试文字换成新文字，走 catalog.tsv。页尾的全部恢复和卸载时自动恢复需要新做。
