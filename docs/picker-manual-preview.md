# Pulse 对话框手工体验

本入口使用已构建的真实 Pulse 对话框，仅验证外观、浏览、输入和选择。不是 Edge/其它软件已完成接管的证明；新版事件接口仍在修复。

双击 `test-pulse-dialog-ui.cmd` 可重新打开。每次建立一个独立测试目录和空的 selection.txt。窗口最多保留 10 分钟。

1. 看文件名、列表、地址栏是否清晰，是否与 Pulse 一致。
2. 调整窗口大小，检查文字、按钮是否裁切或重叠。
3. 在文件名框输入中文，测试选中、复制、粘贴、退格及光标。
4. 浏览目录或返回测试目录，选择 selection.txt，点击打开；也可点击取消。

此入口的打开操作只返回路径，不启动该文件。浏览期间请不要用删除、重命名等操作改动自己的文件。打开/取消后测试程序退出；再次双击入口可重测。

反馈请注明操作步骤、发生了什么、是否每次出现；截图有助于检查模糊、裁切或错位。

当前限制：第三方标准事件接口的运行测试尚未全部通过，Edge 全面接管与 Save 未完成验收；上一次主程序输入框 8 项通过，v1 输入回归为 25 项/1 失败（第二次真实回车释放未被测试线程观察到），不能称完整功能通过。
