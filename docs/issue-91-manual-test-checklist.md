# Issue #91 真机测试清单（浮动预览跟随列表选中项）

- 被测改动：本分支（`91-preview-follow-selection`，基线 `f2c3c95` / v1.0.52）
- 设计说明：`docs/issue-91-preview-follow-selection-plan.md`
- 目标：确认按 `Space` 打开浮动预览窗口后，**点击或方向键切换列表选中项时预览内容立即跟随**，
  且不破坏原有的删除邻接、预览窗内翻页、不可预览项保持等行为。
- 状态：**待验证。** 自动化部分已通过（见 §6），下面每一项都需要在真机窗口里手动过一遍。

---

## 0. 准备（约 5 分钟）

### 0.1 安装与版本确认

1. 装包含本改动的构建（自己 `cmake --build build-ci --target pulse` 出来的，或取本仓库 fork 的预发布）。
2. 建议用隔离实例测试，避免污染日常配置与预览缓存：

   ```powershell
   & "C:\Program Files\Pulse\Pulse.exe" --test-instance
   ```

### 0.2 造测试素材

```powershell
$root = "$env:USERPROFILE\Desktop\pulse-follow-test"
New-Item -ItemType Directory -Force -Path $root | Out-Null
# 逐行跟随的图片序列（§3.2 用）
1..8 | ForEach-Object {
    New-Item -ItemType File "$root\pic-$_.png" -Force | Out-Null
    "$_" * 64 | Set-Content "$root\pic-$_.png"
}
# 视频（§3.3 用）：任意 mp4，文件名排序放在图片之后
1..2 | ForEach-Object { New-Item -ItemType File "$root\movie-$_.mp4" -Force | Out-Null }
# 混排的多种扩展名（§3.9 用）
'note.txt','data.bin','readme.md','sheet.xlsx' | ForEach-Object {
    New-Item -ItemType File "$root\$_" -Force | Out-Null
}
# 一个子目录（§3.4 用）
New-Item -ItemType Directory -Force -Path "$root\subfolder" | Out-Null
```

> 图片必须是**真实**图片，预览才会走图像渲染路径；纯文本改名成 `.png` 只能验证「内容切换」，
> 验证不了缩放/播放状态那几行。

### 0.3 关键前提

- 预览窗**失焦不关闭**是既有行为，所以「点回列表继续操作」时窗口应仍在。
- 每次换选中项前，确认焦点在**文件列表**（点一下列表空白处），不是在地址栏或预览窗内。

| # | 操作 | 期望 | 结果 |

| 3.8 | 内容搜索结果里上下切换选中项 | 预览跟随正确，**不出现上一帧的错位内容**（异步 resolve 的跳过逻辑生效） | ☐ |
| 3.9 | 快速连续点击 10 个不同扩展名的文件 | 无崩溃、无窗口句柄泄漏（任务管理器观察句柄数） | ☐ |

> 3.1 与 3.5 是两个 `Update()` 入口最容易互相覆盖的地方，务必实测，不能只靠推理。
