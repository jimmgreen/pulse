1.0.59 · 2026-11-09

这一版重点完善详情预览、工具栏、多窗口和工作区，增强 Pulse 助手的对话与模型管理，并带来实验性的打开/保存对话框接管。

### 详情预览与工具栏

- [修复] 详情侧栏预览不再遮挡排序、分组弹窗；关闭弹窗后保留预览内容和横竖滚动位置，退出动画与快速重新打开时也能正确恢复。
- [修复] Markdown 预览的横向、纵向滚动条现在可以按住拖动，支持点击轨道翻页；拖动不再误选正文，取消或失去鼠标捕获后正确结束。
- [改进] 自定义工具栏中的内置按钮名称和说明支持换行，按可用宽度调整列数，减少英文、高缩放和窄窗口下的大量省略号。
- [改进] 工具栏「更多」菜单更紧凑；打开工具栏自定义面板时，详情预览不再遮住面板。
- [改进] 快速预览增加窗口尺寸预设、播放快捷键和可配置的鼠标长按临时预览；点击视频画面即可暂停或继续播放。
- [改进] 表格预览显示工作表单元格填充色，并改善 GIF 预览的解码预算与内存管理。

### 浏览、搜索与文件列表

- [新功能] 地址栏支持路径补全、从当前目录补全相对路径，以及直接打开文件；面包屑增加子文件夹菜单，侧栏驱动器增加操作菜单。
- [改进] 图片、音乐和视频文件夹增加对应的媒体信息列与分组选项；详细信息视图支持拖动列标题调整顺序。
- [改进] 重新设计驱动器容量条，在侧栏和「此电脑」详情中显示容量信息；回收站默认按删除时间从新到旧排列。
- [修复] 全盘搜索和快速搜索遗漏当前用户回收站文件的问题；搜索结果标明回收站来源，支持还原并刷新结果。
- [修复] 切换到搜索结果时短暂显示旧目录，以及回收站文件与原位置同名文件混淆的问题。
- [改进] 筛选输入框支持拼音匹配，修复偶发黑色矩形闪烁；统一侧栏子项缩进，收藏夹同时支持文件和文件夹，隐藏未连接的手机设备项。
- [修复] 「此电脑」排序方式未正确记忆的问题。

### 多窗口与工作区

- [改进] 窗口总览支持移动、调整大小和最大化；排列面板统一提供并排、上下、三列、平铺、主次、层叠及合并窗口等操作，并支持撤销排列。
- [改进] 层叠保留各窗口原有大小，最大化窗口使用还原尺寸；仅在超出屏幕可用区域时缩小窗口。
- [改进] 工作区采用统一的彩色图标和层级布局，支持窗格拖动换位、右键操作和自定义颜色；可在当前或新标签页恢复工作区。
- [改进] 分栏悬停激活增加短暂延时，工具栏、分隔线和边缘不再误触切换；编辑和拖动时保留当前窗格。
- [修复] 恢复工作区后切换分栏布局可能崩溃，以及普通导航或视图切换误报「分栏已变化」的问题。
- [修复] 托盘窗口恢复时丢失隐藏前的位置；任务栏窗口标记仅统计已打开窗口。Ctrl+N 恢复为新建窗口。

### Pulse 助手

- [新功能] 对话历史支持搜索、重命名、置顶和保留期限设置；消息支持编辑、重新生成及回答版本切换。
- [改进] 回答支持更丰富的排版和文字选择，助手面板滚动条可以拖动。
- [改进] 模型服务、密钥和语音连接统一到助手设置；提供服务预设，区分仅聊天模型，按模型显示可用思考等级，并增加 Xiaomi MiMo 预设。
- [修复] 尚未配置模型时助手开关无法点击，以及切换主题后部分设置字段未及时重绘的问题。

### 打开和保存对话框（实验性）

- [新功能] 可在受支持的程序中使用 Pulse 的打开和保存界面，统一浏览、多选、筛选和保存操作。
- [改进] 接入独立对话框宿主，完善传统和新版对话框、32 位程序及管理员场景的兼容处理；等待过程中可以关闭对话框。
- [改进] 不支持接管时保留系统原生界面。跳转条显示与自动跳转设置统一到「启动与集成」。
- [修复] 跳转条设置无法点击或未即时生效，以及下拉列表位置偏移的问题。

### 增强包更新

- [改进] 媒体预览增强包（FFmpeg）更新到 1.0.5，增加内嵌文字字幕渲染与字幕时间偏移支持；播放器界面的相关操作由新版 Pulse 提供。
- [改进] 图片预览增强包更新到 1.0.3，更新 HEIF/HEVC 解码依赖，改善初始化可靠性。已安装的增强包可在设置中更新。
- [改进] 内容搜索与 AI 增强包随 Pulse 1.0.59 同步构建，分别提供 Windows 10/11 与 Windows 8.1 兼容版本，按需下载并校验。

### Extensions / 原生插件 SDK（开发预览）

- [新功能] 开放 Windows x64、C++20 原生插件源码 SDK，提供命令、界面、文件服务、预览、后台任务和设置页等接口，以及示例和作者工具。
- [改进] 插件支持显式安装与启用、多文件包、整包升级和回退；当前为 SDK preview 3，接口与兼容性仍在打磨，尚非稳定 SDK / ABI 1.0。
- 本版仅介绍开发预览能力，不随 Release 分发本地构建的插件包；参考插件需要另行构建、准备依赖、安装和启用。使用说明见仓库的增强包文档入口。

### 文件操作、外观与安装

- [改进] 已选项目可从非文字区域开始拖动，未选行空白处仍支持框选；拖动预览与操作提示不再相互遮挡。
- [修复] 新建文件夹操作正确面向当前窗格，并处理需要管理员权限的场景；未安装 Windows Terminal 时，「在终端中打开」可改用 PowerShell 或命令提示符。
- [改进] 完善「固定到开始」的独立进程处理，保留完整的「打开方式」程序列表，并让内置右键菜单遵循菜单偏好设置。
- [改进] 使用新的磨砂玻璃文件夹图标，统一滚动条、按钮边框和局部文字样式；普通反馈更安静，胶囊提示去掉倒计时行。
- [改进] 重新整理「启动与集成」和安装界面；增强包下载失败时提供更明确的原因，按设置选择下载源，并在文件校验不匹配时尝试下一来源。

### 升级说明

- 原生插件与 Pulse 在同一进程、相同系统权限下运行，并非安全沙箱。请仅运行可信插件；更新已加载的插件后需要重启 Pulse，SDK 预览号变化时可能需要重新编译插件。
- 旧的 7-Zip 下载增强包已退役。7z/RAR 预览及解压现需另行安装并启用原生压缩包插件，旧包不会自动转换；内置 ZIP 功能不受影响。
- 文件对话框接管仍属实验性功能，不保证兼容所有程序。安装包继续区分 Windows 10/11 普通版与 Windows 8.1 兼容版，不再提供新的便携 ZIP 版本。
