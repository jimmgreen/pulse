1.0.62 · 2026-11-26（内测版）

这一版为内测版本，重点升级了新版打开／保存对话框（Pulse 选中区、暂存托盘联动、跨文件夹多选篮子、另存为命名建议与压缩包内选文件，并统一了对话框排版与字号体系），全面重构并收敛了全应用动画与交互响应（首帧即刻可读可点、消除空闲重绘与动画卡滞），同时带来全局搜索排序分组、高级搜索正则、右键菜单层级整理、压缩包快速预览增强、快速预览沉浸式看图、拖动晃动呼出暂存托盘与 7-Zip 图标样式切换，并集中修复了局部重绘、文件操作进度、高对比度与右键菜单等方面的大量问题。请在测试机或可以接受问题的环境中使用，遇到问题时附上诊断信息反馈。

### 动画与交互响应

- [改进] 重构视图模式切换动画：目标单元格和文件名首帧立即可读、立即响应点击，不再出现整行飞跃、文字延迟或画面与命中区域错位；仅已有图标在目标格内短暂平滑收敛，并以墙钟时间封顶，慢帧不再拖长动画。
- [改进] 侧边栏折叠收尾改用平滑归零曲线，消除动画最后一帧突然跳变的问题；磁盘容量条即时呈现真实比例，不再播放装饰性进度动画。
- [改进] 简化明暗主题切换为轻量短渐隐过渡（不再每帧重建圆形遮罩几何），降低切换开销；标题栏主题按钮改为直接切换明暗形态并统一按钮线条粗细。
- [改进] 确认对话框、右键菜单、工具栏自定义面板、标签页切换器（MRU）和窗口切换器统一改为首帧即完整可读：移除逐项错峰延迟和阻断命令执行的关闭动画，只保留克制的容器与选中态过渡。
- [改进] 降低 AI 助手面板的动画能耗：移除空状态持续呼吸重绘、状态文字反复扫光和麦克风扩散光环，保留运行状态提示与语音录入时的实时电平／计时；安装向导切页改为原地稳定呈现，隐藏或静止时自动停止定时器。
- [改进] 排序／分组滚轮打开时直接停在当前选中项，不再滚过其他选项；快速预览上一项／下一项切换改为更平滑的连续过渡。
- [修复] 修复部分过渡动画（悬停预览卡片、标签切换器、安装向导等）未严格遵循 Windows 系统动画开关的问题，以及静态保持阶段仍持续触发逐帧重绘的问题。
- [修复] 修复确认对话框首帧空白或闪烁的问题：窗口显示前先完成文字与排版准备，首帧即完整可读。

### 打开／保存对话框

- [新功能] 新增「来自 Pulse」选中区：主窗口当前选中的文件以紧凑卡片形式出现在对话框顶部，带有 Pulse 图标、公共父目录提示、实色类型方块和 Alt 0 快捷键，单选一键「使用」、多选「全部加入」。
- [新功能] 侧边栏集成「暂存托盘」并支持分页浏览与拖入文件；新增「打开后从暂存托盘移出」选项（按程序记住），仅移出普通文件引用而不删除原文件，同时保留截图、文字等临时内容避免调用程序读取失效。
- [新功能] 支持跨文件夹多选「已选篮子」（最多 1024 项），底部实时汇总文件数、大小和来源文件夹数；支持直接进入并选取 7-Zip 压缩包内的文件。
- [新功能] 另存为模式新增快捷命名建议（版本 +1、加日期、原文件名、去掉副本）、实时同名冲突提示、格式分段切换与常见格式说明，以及原文件所在位置和 Git 仓库根目录快速跳转；保存后在主窗口提示并支持快速定位。
- [改进] 对照新版设计统一对话框全区域字号与视觉层级（标题栏、地址栏、「已打开的文件夹」横向滚动胶囊条、Pulse 选中卡片、筛选栏与底部区域），支持「新文件」角标、右侧预览面板开关及与主窗口同步排序／分组。
- [修复] 修复暂存托盘中带长路径前缀的文件与目录列表路径匹配失败，导致选中状态或重复判定异常的问题。
- [修复] 修复另存为模式下误显示「打开后从暂存托盘移出」选项，以及右侧预览中部分模板占位符未替换和重复圆点的问题。
- [修复] 修复对话框侧边栏「常用」分组标题过长时与右侧固定（图钉）图标重叠的问题。
- [修复] 修复自动接管记录在异常缺失或跨安装残留状态下的恢复与校验问题，以及关闭阶段的回调线程竞态。

### 全局搜索与高级搜索

- [新功能] 全局搜索支持按相关性、名称、修改日期、大小、路径和扩展名排序，并可按匹配程度、文件类型、修改日期、所在文件夹或大小分组，支持一键折叠／展开全部分组及「应用排在最前」。
- [新功能] 高级搜索支持正则表达式（ECMAScript，不区分大小写）并实时提示语法错误。
- [改进] 优化双击 Ctrl 唤起全局搜索的触发判定与多显示器定位，每次唤起跟随鼠标所在屏幕并保持尺寸一致。
- [修复] 修复双击 Ctrl 期间夹杂鼠标点击、滚轮或左右 Ctrl 同时按下时误触发，以及前台焦点被系统拒绝或附属弹窗归属判断不准导致意外关闭的问题。
- [修复] 修复流式搜索结果陆续到达并排序时选中行发生偏移，以及高对比度模式下选中项前景色未即时更新的问题。

### 右键菜单与系统菜单管理

- [新功能] 新增「整理右键项目…」层级视图：可查看已在 Pulse 中出现过的右键菜单及其子菜单项，逐项隐藏、恢复或拖动排序（仅影响 Pulse，下次右键生效）。
- [改进] 完善「响应较慢的菜单（≥150 ms）」耗时记录，支持仅在 Pulse 停用而不改动 Windows 资源管理器；完善其他工具禁用项的恢复与系统改动前的自动备份和逐步撤销。
- [改进] 改进右键菜单图标上传与测量缓存，复用未变化的图标像素；系统「新建」菜单改用异步加载，避免阻塞弹出。
- [修复] 修复右键菜单中含空格的级联子命令键解析错误，以及「打开方式」历史项在合并或刷新后条目错乱、无法单独配置的问题。
- [修复] 修复打开下级子菜单或发生注册表变更时，旧菜单会话覆盖新缓存或导致当前显示命令映射错位的问题。
- [修复] 修复高对比度模式下菜单项、图标及副文案选中高亮前景色不一致的问题。
- [新功能] 右键菜单新增「在另一栏打开」，以及「复制到 ▸」「移动到 ▸」子菜单，可直接投送到其他已打开的位置。

### 浏览、界面与窗口

- [新功能] 新增拖动文件晃动（Drag Shake）快速呼出暂存托盘，方便跨窗口暂存与投放。
- [新功能] 拖动文件时列表可继续滚过末尾，方便投放到最后一项之后（默认开启，可在设置中关闭）。
- [改进] 拖放到项目上时，仅在松手位置位于文件名上才会用该程序打开，落在其他位置按放入文件夹处理，减少误打开。
- [修复] 修复设置中暂存托盘「浮动架出现在」和「晃动灵敏度」选项无法点击的问题（晃动灵敏度需先开启晃动呼出）。
- [改进] 优化列表视图列宽计算与标签页拖拽分离体验。
- [修复] 修复首次启动窗口尺寸按主显示器 DPI 计算并限制在工作区范围内的问题，以及启动时扩展包激活时机问题。
- [修复] 修复局部重绘下脏区外旧像素残留，以及多窗口共享文件夹缩略图缓存时单个窗口的刷新误取消另一窗口请求的问题。
- [修复] 修复重命名输入框被吸顶分组标题遮挡、反向滚动滚轮仍沿旧方向滑行一段距离，以及行内悬停按钮在鼠标捕获／重新进入后状态丢失的问题。
- [修复] 修复扩展设置页轮询刷新触发整页重排并打断滚轮滚动，以及局部重绘裁切控件焦环或阴影的问题。
- [修复] 修复资源管理器窗口接管在定位文件过渡期间提前误判状态，以及部分非标准浏览调用回退系统资源管理器时的路由问题。

### 文件操作

- [改进] 改进大文件与递归文件操作的剩余时间（ETA）估算，区分刷盘收尾与目录完成耗时，总量未知或收尾阶段状态更清晰；完善交互式文件操作对话框的链接、范围与目标处理。
- [修复] 修复进度卡片在任务完成过渡期间被旧定时器误隐藏，或手动隐藏后又被状态刷新强行重新显示的问题。
- [修复] 修复小文件批量操作的 ETA 被字节速率阈值误隐藏、暂停恢复后残留旧阶段估算，以及回退删除路径误继承原生计数的问题。
- [修复] 修复粘贴远程文件列表时因重试截止过早丢弃已就绪结果，以及避免对已部分执行的粘贴操作重复投放。

### 预览与 7-Zip 压缩包

- [新功能] 快速预览与右侧详情面板内的压缩包浏览支持缩略图、排序、尺寸滑块，以及直接从压缩包向外拖出或向内拖入文件。
- [新功能] 快速预览新增沉浸式看图（默认开启）：底部胶片条缩略图导航，鼠标静止 2.5 秒后控件自动淡出，可筛选「图片」让 ←/→ 跳过视频与其他文件，播放视频时胶片条自动收起；可在 ⋯ 菜单切回经典样式并记住选择。
- [新功能] 7-Zip 增强包（1.1.0）支持在常规设置页切换压缩包图标样式（含拉链文件夹与彩色文档风格）并配置各格式接管。

### 升级说明

- 本版为内测版本，沿用三段版本号，可以直接覆盖安装 1.0.61；内测期间不会推送到自动更新。
- 文件对话框接管仍属实验性功能，不保证兼容所有程序；遇到问题可在「软件接管记录」中导出诊断。
