1.0.59 · 2026-11-09

This release improves Details previews, toolbar customization, windows and workspaces, expands the Pulse assistant's conversation and model management, and introduces experimental open/save dialog integration.

### Details previews and toolbar

- [Fixed] Details previews no longer cover Sort or Group flyouts. Closing a flyout preserves preview content and both scroll positions, including during closing animations and rapid reopening.
- [Fixed] Markdown preview scrollbars now support horizontal and vertical thumb dragging and track-click paging. Dragging no longer selects body text, and cancellation or loss of mouse capture ends the gesture correctly.
- [Improved] Built-in toolbar button names and descriptions wrap, and the customization panel adapts its column count to the available width, reducing excessive ellipses in English, at higher scaling and in narrow windows.
- [Improved] A more compact toolbar More menu. Details previews no longer cover the toolbar customization panel.
- [Improved] Quick Look gains window-size presets, playback shortcuts and configurable mouse press-and-hold previews. Click a video to pause or resume playback.
- [Improved] Spreadsheet previews display cell fill colors, with improved decoding budgets and memory management for GIF previews.

### Browsing, search and file lists

- [New] Address-bar path completion, relative-path completion from the current folder and direct file opening. Breadcrumbs gain child-folder menus, and sidebar drives gain action menus.
- [Improved] Picture, music and video folders gain media-specific columns and grouping options. Drag column headers to reorder them in Details view.
- [Improved] Redesigned drive-capacity bars and capacity information in the sidebar and This PC details. The Recycle Bin defaults to most recently deleted first.
- [Fixed] Full-disk and quick search now include the current user's Recycle Bin files, identify their source, support restoration and refresh the results afterwards.
- [Fixed] Stale folder contents appearing during search transitions, and confusion between recycled files and live files at the same original path.
- [Improved] Pinyin matching in the filter field, with intermittent black flashes fixed. Consistent sidebar indentation, Favorites support for both files and folders, and hidden entries for disconnected phones.
- [Fixed] This PC sort-order persistence.

### Windows and workspaces

- [Improved] Window overview can be moved, resized and maximized. One arrangement panel provides side-by-side, stacked, three-column, tiled, main-and-secondary, cascade and merge actions, with undo for arrangements.
- [Improved] Cascade preserves individual window sizes and uses restore sizes for maximized windows. Windows shrink only when they exceed the available screen area.
- [Improved] Consistent color icons and hierarchy in workspaces, with drag reordering, pane context menus and custom colors. Restore a workspace in the current tab or a new tab.
- [Improved] A short delay before hover-activating another pane. Toolbars, dividers and edges no longer trigger accidental switches; editing and dragging retain the current pane.
- [Fixed] Crashes when switching split layouts after restoring a workspace, and false layout-changed warnings during ordinary navigation or view-mode changes.
- [Fixed] Tray windows losing their previous placement when restored. Taskbar window indicators count only open windows. Ctrl+N once again opens a new window.

### Pulse assistant

- [New] Search, rename and pin conversations, with configurable history retention. Edit messages, regenerate answers and switch between answer versions.
- [Improved] Richer answer formatting and text selection, with draggable assistant-panel scrollbars.
- [Improved] Model services, credentials and voice connections are managed in assistant settings. Service presets distinguish chat-only models, expose model-specific thinking levels and now include Xiaomi MiMo.
- [Fixed] The assistant enable switch being unclickable before model setup, and settings fields not repainting promptly after a theme change.

### Open and save dialogs (experimental)

- [New] Use Pulse's open and save interface in supported applications, with consistent browsing, multi-selection, filtering and saving.
- [Improved] A separate dialog host, with compatibility handling for legacy and modern dialogs, 32-bit applications and administrator scenarios. Dialogs can be closed while waiting.
- [Improved] Unsupported dialogs retain the native interface. Jump-bar visibility and automatic navigation settings now live under Startup & integration.
- [Fixed] Jump-bar settings that could not be clicked or did not apply immediately, and misplaced drop-down lists.

### Enhancement-pack updates

- [Improved] The media preview pack now uses FFmpeg pack 1.0.5, adding embedded text-subtitle rendering and subtitle timing offsets. Related player controls are provided by the newer Pulse application.
- [Improved] Image preview pack 1.0.3 updates HEIF/HEVC decoding dependencies and improves initialization reliability. Installed packs can be updated in settings.
- [Improved] Content-search and AI enhancement packs are built alongside Pulse 1.0.59 for both Windows 10/11 and Windows 8.1, with on-demand downloads and file verification.

### Extensions / native plugin SDK (developer preview)

- [New] A Windows x64 C++20 native plugin source SDK, with command, UI, file-service, preview, background-task and settings-page interfaces, plus examples and authoring tools.
- [Improved] Explicit installation and enablement, multi-file packages, and whole-package upgrades and rollback. This is SDK preview 3: interfaces and compatibility are still being refined, not a stable SDK / ABI 1.0 release.
- This release documents the developer preview but does not distribute locally built plugin packages. Reference plugins require separate builds, dependencies, installation and enablement. See the repository's extension documentation index for instructions.

### File operations, appearance and installation

- [Improved] Drag selected items from non-text areas while retaining marquee selection on unselected row whitespace. Drag previews no longer overlap operation hints.
- [Fixed] New-folder actions target the current pane and handle locations requiring administrator rights. Open in terminal can fall back to PowerShell or Command Prompt when Windows Terminal is unavailable.
- [Improved] Isolated handling for Pin to Start, complete Open with application lists, and menu preferences applied to built-in context menus.
- [Improved] A new frosted-glass folder icon, consistent scrollbars, button borders and local typography. Routine feedback is quieter, and capsule notifications no longer show a countdown line.
- [Improved] Reorganized Startup & integration and installation screens. Clearer enhancement-pack download errors, respect for the selected download source, and fallback to the next source when a file fails verification.

### Upgrade notes

- Native plugins run in the Pulse process with the same operating-system permissions, not in a security sandbox. Run only trusted plugins. Restart Pulse after updating a loaded plugin; a new SDK preview number may require recompiling plugins.
- The old downloadable 7-Zip pack has been retired. 7z/RAR previews and extraction now require a separately installed and enabled native archive plugin; old packs are not automatically converted. Built-in ZIP features are unchanged.
- Open/save dialog integration remains experimental and does not support every application. Separate installers remain available for Windows 10/11 and Windows 8.1; new portable ZIP editions are no longer provided.
