# Pulse 1.0.8

## 改进

- 更新清单和安装包默认使用加速下载，依次尝试 ghproxy.net、gh-proxy.com，连接失败后自动回退到 GitHub，无需设置。
- 切换下载来源时清空未完成内容，继续验证更新清单签名和安装包 SHA-256；取消下载后不再重试。

## 修复

- 减少点击已选中文件或文件夹名称后进入重命名的额外等待，保留快速双击打开的行为。
- 重命名命中检测和输入框布局不再触发不必要的详情查询。

## 验证

- 本地 Release 构建、更新回退测试和界面检查通过；两个加速源的在线清单签名与安装包哈希校验通过。
- 本地 16 个测试程序中 15 个通过；操作测试仍存在此前的回收站删除失败。发布流程会对普通版和 Windows 8.1 兼容版重新构建并运行回归测试，通过后才发布。
