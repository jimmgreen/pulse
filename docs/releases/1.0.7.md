# Pulse 1.0.7

## 改进

- 固定标签默认保留名称，支持右键重命名、恢复自动名称及选择颜色标记；设置中可切换为仅图标。
- 分栏列表空白处单击可后退；没有历史时返回上级目录，并与框选、双击和取消操作区分。
- 统一筛选及设置页分段控件样式，改善状态栏长文件名显示。
- 补齐主要菜单、标签管理、文件操作对话框、设置和状态提示的中英文本地化。
- 更新仓库中的 icon.png 图片。

## 修复

- 修复侧边栏滚动内容覆盖顶部工具栏的问题。
- 修复子菜单颜色标记无法点击及缺少悬停反馈的问题，复用公共菜单命中逻辑。
- 隐藏标签路径提示中的内部长路径前缀，正确显示网络共享路径。
- 保留语言切换前的字符串引用，避免后台任务读取失效的本地化文字。

## 验证

- 本地完整自测 608 项通过，覆盖双分栏空白点击和不同缩放下的颜色子菜单交互。
- 本地双语资源、控制器、预览及界面材质回归测试通过；补充普通、网络与长路径显示测试。
- 第三方菜单及底层原始错误信息仍可能使用来源自身的语言。
