1.0.61 · 2026-11-16 (internal test)

This is an internal test build. It brings 7-Zip archive takeover, a redesigned extension store and extension settings, the Desktop Organizer extension in the store, diagnostics and managed launch for the open/save dialog takeover, a new file conflict dialog, and content previews for Office documents. Use it on test machines or where problems are acceptable, and include diagnostics when you report an issue.

### 7-Zip archives

- [New] The 7-Zip pack can take over archive files, with a separate icon for each format. Choose which formats to take over and jump to Windows Default Apps to finish the association.
- [New] Archives with no associated program can be smart-extracted through 7-Zip directly.
- [Improved] The context menu's Extract offers smart extract, extract to a folder of the same name, or extract here, and the menu shows the chosen mode.
- [Improved] Quick compress lets you choose 7z, zip, tar and other formats and the compression level. Set what double-clicking an archive does, and keep the password you entered until Pulse exits.

### Extension store and settings

- [Improved] The store is redesigned with Discover and Installed views, category filters and search; official packs show a verified badge and their own product art.
- [New] Install an extension from a local file, with its source and signature shown first, and Restart now when a change needs a restart.
- [Improved] Offline, the store shows the last catalog it loaded and installed extensions stay configurable; it warns when the catalog has expired or a publisher key has rotated.
- [Improved] Uninstalling can also remove the extension's saved settings and grants, and shows when background tasks are being stopped.
- [Improved] An extension's own settings page opens with the same header as the 7-Zip detail page (icon, publisher, status chips) and two tabs: common settings and context menu.
- [Setting] Per extension, choose how its context-menu commands appear (default, flat in the main menu, in a submenu, or hidden), turn each command on or off, and reset at any time.
- [Fixed] Locally installed extensions showed as version 1.0.0 in the store; they now show "Local build" with their revision.
- [Fixed] Extra chooser rows at the top of an extension's settings page and a grey band across its content.

### Desktop Organizer (extension store)

- [New] The Desktop Organizer extension 1.0.16 is in the extension store: it sorts the files on your desktop into groups and file tiles, alongside app tiles and widgets.
- [New] Widgets for weather, calendar (with the Chinese lunar calendar and festivals), to-do, notes, photos, system, clock, disks, the Recycle Bin and more, in several sizes, each previewed before you add it.
- [New] Click a widget to open its detail card: weather shows feels-like, humidity, wind, hourly and 6-day forecasts; the calendar pages by month with lunar dates and festivals; the clock adds world clocks and the week number; disks list the usage of each drive.
- [New] Drag a widget onto another to stack them (up to six), and switch with the dots or arrows.
- [Setting] The photos widget can use a folder you choose, an interval and shuffle; notes can have a colour.
- [Improved] App tiles show up to two rows of apps and page through the rest; apps start on click, and the pressed look recovers at once even when an app is slow to start.
- [Improved] Tick off or delete to-dos in place, and empty the Recycle Bin from its widget.
- [Improved] The system widget's CPU usage matches Task Manager.
- [Improved] Menus, popups, buttons and text boxes use Pulse's own controls, and menus show check and choice marks.
- [Improved] The extension reuses Pulse's own text engine, so the package is smaller.

### Open/save dialog takeover

- [New] Takeover history lists the last 12 apps with each result, the reason and what to do, merges repeated events and can export diagnostics; it never records file names or contents.
- [Improved] Running apps that still hold an old takeover component are listed for reopening, and processes that could not be checked are reported as such.
- [New] Managed launch starts a chosen .exe with the verified 32- or 64-bit component; apps that truly need elevation use a separate administrator entry, which never elevates the Pulse window.
- [Improved] Automatic takeover shows the x64 and x86 components and their registration separately, flagging conflicts and read errors.
- [Improved] Folder quick jump understands pinyin initials and path fragments, draws on recent, everywhere and Pulse tabs, and can create a folder or save right there.
- [Improved] Better compatibility with WinRT pickers, legacy API dialogs and Save As, with the destination shown when saving.

### File operations

- [New] A new name-conflict dialog compares the size and modified time of the existing file and the incoming copy or move, and marks the recommended choice.
- [Improved] On a conflict, replace, keep the existing file, or save the incoming one under another name; folders of the same name merge.
- [Improved] File operations can continue in the background, and failures offer Copy details.

### Browsing and interface

- [New] The sidebar gains a rail to switch between workspaces, quick access, saved searches, drives, tags and networks.
- [Improved] Settings are reorganised with a group column and a short description for each section; the two context-menu settings are split into scope cards with real tab-strip previews.
- [Setting] File double-click interval, which can follow the system and never changes Windows settings.

### Search and index

- [New] Local FAT32 and exFAT drives (including USB drives, external disks and memory cards) join the full-disk index and stay up to date as files change; plugging, unplugging or a new drive letter is picked up on its own.
- [New] Locations that are not indexed can be searched live, with results arriving as they are found.
- [Improved] The index service uses less memory: pinyin search data is read from disk as needed, and unused memory is released when idle or in the background.
- [Improved] Folder sizes are calculated faster with less memory.
- [Improved] Server folders are indexed faster using the current Windows sign-in, and the network index process no longer starts when no server folders are added.

### Preview

- [New] Content previews for Office documents: Word (including legacy .doc), spreadsheets and presentations are shown in content mode (not the original layout), and presentations can be paged slide by slide.
- [Improved] When you scroll quickly through a large folder, cached thumbnails show first and the rest are made once you slow down, so scrolling stays smooth.
- [Improved] The thumbnail cache keeps small compressed thumbnails so folders show them sooner when reopened; small files that are quick to render are no longer written to the disk cache, saving space.
- [Improved] Improved video preview playback.

### Installer

- [Fixed] The installer always carries both the x64 and x86 dialog components, so PCs that have the x86 component no longer fail to upgrade.

### Upgrade notes

- This is an internal test build. The version keeps three parts and installs directly over 1.0.60; it is not offered through automatic updates.
- The Desktop Organizer extension needs Pulse 1.0.60 or later; install and update it from the extension store. It is not part of this installer.
- The file dialog takeover remains experimental and may not work with every program; export diagnostics from the takeover history if something goes wrong.
