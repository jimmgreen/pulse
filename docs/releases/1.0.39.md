- 详细信息视图的列宽改为按内容自适应：日期、类型、大小三列会按当前语言、字体、缩放比例和日期格式实测所需宽度，不再使用固定宽度，省下的空间都留给文件名；拖动过的列会记住手动宽度，双击列分隔线即可恢复自适应宽度。
- 窗格变窄时按"类型 → 日期"的顺序自动隐藏次要列，保证文件名始终可读；被隐藏列的信息（修改时间、搜索结果所在文件夹）会显示在鼠标悬停提示里。
- 搜索结果窗格较窄时，自动切换为双行显示：文件夹路径显示在文件名下方，不再挤成一列被截断。
- 路径改为中间省略，保留盘符和最后几级文件夹（例如"C:\…\boost\regex"）；文件名、类型等过长时统一以省略号结尾，不再被硬生生截断。
- 新增"智能日期"：近期时间显示为"今天 14:32""昨天 09:10""周三 18:00"，今年内显示"4月13日 22:28"，更早的只显示日期。
- 新增斑马纹行：详细信息视图隔行加一层淡底色，宽列表更容易横向对齐。
- 类型列前增加彩色扩展名标签（EXE、DLL、PDF、ZIP 等按类别着色）；文件名中的扩展名略微淡化，先看清主体名称。
- 大小列数字右对齐、单位单独成列，KB/MB 上下对齐，便于比较。
- 搜索高亮改为强调色浅底加下划线，比原来的琥珀色描边框更柔和。
- 设置 → 外观新增"智能日期""斑马纹行""大小比例条"三个开关；前两项默认开启，大小比例条默认关闭。
