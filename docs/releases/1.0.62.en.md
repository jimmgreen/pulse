1.0.62 · 2026-11-26 (internal test)

This is an internal test build. It upgrades the open/save dialog with a compact Pulse selection strip, staging tray integration, cross-folder multi-select basket, Save As naming suggestions, in-archive selection and unified typography; overhauls motion and responsiveness across the app so content is immediately readable and interactive without idle repaints; adds global search sorting and grouping, regex in advanced search, hierarchical context-menu organisation, richer archive previews, an immersive Quick Look photo viewer, drag-shake staging tray reveal and 7-Zip archive icon styles; and fixes a wide range of partial-redraw, file-operation progress, high-contrast and context-menu issues. Use it on test machines or where problems are acceptable, and include diagnostics when you report an issue.

### Motion and responsiveness

- [Improved] Reworked view-mode switching animations: target cells and file names are immediately readable and clickable on the first frame instead of rows travelling across the list or lagging behind hit targets; only existing icons settle briefly within their target slots under a wall-clock deadline so slow frames never stretch motion.
- [Improved] Smooth zero-slope tail curve for sidebar collapse eliminates the last-frame snap, and drive capacity bars display their real proportion immediately instead of playing a decorative fill animation.
- [Improved] Replaced the per-frame circular-mask theme reveal with a lightweight crossfade, and switched the title-bar theme button to direct light/dark shapes (no rotation) with unified caption icon stroke weight.
- [Improved] Confirmation dialogs, context menus, toolbar customisation popups, the MRU tab switcher and window switcher all render readable content on the first frame—removing item stagger delays and close animations that delayed command execution while keeping brief container and selection transitions.
- [Improved] Reduced animation overhead in the AI panel by removing idle breathing repaints, repeating status-text shimmer and expanding mic rings while preserving active indicators and live voice levels/timers; setup wizard page switches stay anchored in place and stop timers when hidden or idle.
- [Improved] Sort/group drum wheels open directly on the current selection instead of rolling past other values, and Quick Look prev/next transitions keep content and text legible throughout navigation.
- [Fixed] Transitions in hover preview cards, the tab switcher and the setup wizard not consistently honouring the Windows system-animations setting, and static holds continuing to schedule frame-by-frame repaints.
- [Fixed] Blank or flickering first frames in confirmation dialogs by preparing layout and text before showing the window.

### Open/save dialog

- [New] Selected items from the Pulse main window appear in a compact card strip at the top of the dialog with the Pulse mark, shared parent folder, colour-coded type tiles and Alt 0 shortcut—single-click Use in single-select or Add all in multi-select.
- [New] The staging tray is integrated into the picker sidebar with paging and drag-in support; a per-app "Remove from staging tray after opening" option removes ordinary file references without deleting the files while keeping temporary screenshots and text intact.
- [New] Cross-folder multi-select basket (up to 1,024 items) with live count, total size and folder summary, plus browsing and picking files directly inside 7-Zip archives.
- [New] Save As adds quick naming suggestions (Version +1, Add date, Original name, Remove copy suffix), live name-conflict feedback, segmented format switching with format notes, quick jumps to the original file folder and Git repository root, and a post-save follow-up prompt in the main window.
- [Improved] Unified typography and visual hierarchy across the entire dialog (title bar, address bar, scrollable Open folders pill strip, Pulse selection card, filter bar and footer), along with New file badges, preview pane toggle and sort/group sync with the main window.
- [Fixed] Long-path prefixed staging tray items failing to match folder listing paths, causing broken selection state or duplicate detection.
- [Fixed] Save mode wrongly showing the "Remove from staging tray after opening" toggle, as well as unsubstituted template placeholders and duplicate bullets in Save previews.
- [Fixed] Long app-pinned section titles in the picker sidebar overlapping the trailing pin icon.
- [Fixed] Recovery and validation of missing or leftover cross-install automatic takeover journals, and shutdown callback races.

### Global search and advanced search

- [New] Global search supports sorting by relevance, name, modified date, size, path and extension, grouping by match, type, date, folder or size, collapsing or expanding all groups, and an "Apps first" option.
- [New] Advanced search supports case-insensitive ECMAScript regular expressions with live syntax validation.
- [Improved] Improved double-Ctrl activation and multi-monitor placement so each summon follows the pointer monitor while preserving DIP size.
- [Fixed] Accidental double-Ctrl triggers when mouse clicks, wheel events or both Ctrl keys overlap, and unexpected dismissal when foreground focus is rejected or owned popups are open.
- [Fixed] Selection drifting as streamed search hits arrive in sorted order, and high-contrast foreground colour not updating immediately on selection change.

### Context menus and system menu manager

- [New] Hierarchical "Organize menu items…" view lets you inspect menus and submenus observed in Pulse, hide or restore items, and drag to reorder them (Pulse only; takes effect on the next right-click).
- [Improved] Better slow menu add-on timing (≥150 ms) with Pulse-only disable separate from File Explorer, plus restoring items disabled by other tools and automatic registry backups with step-by-step undo.
- [Improved] Improved icon upload and measurement caching to reuse unchanged icon pixels, plus asynchronous loading of the system New submenu.
- [Fixed] Parsing of static cascading subcommand keys containing spaces, and Open With MRU entries losing stable identity or customisability across rebuilds.
- [Fixed] Stale menu sessions overwriting invalidated caches or shifting active command mappings when submenus open or registry changes occur.
- [Fixed] Inconsistent highlight foreground colours for menu items, glyphs and secondary text in high-contrast mode.
- [New] Context menus add "Open in other pane" plus "Copy to ▸" and "Move to ▸" submenus for sending items straight to other open locations.

### Browsing, interface and windows

- [New] Shake while dragging files to reveal the staging tray for quick cross-window staging and drop.
- [New] Lists keep scrolling past the last item while you drag, so you can drop below it (on by default, can be turned off in settings).
- [Improved] Dropping onto an item opens with that program only when released over its name; drops elsewhere go into the folder, reducing accidental opens.
- [Fixed] The staging tray "Floating shelf appears at" and "Shake sensitivity" settings not responding to clicks (shake sensitivity requires shake-to-reveal to be on).
- [Improved] Faster list-view column width calculation and improved tab detachment.
- [Fixed] First-launch window size calculation using primary monitor DPI clamped to the work area, and startup activation of extension packages.
- [Fixed] Stale pixels outside dirty regions during partial redraw (Present1), and one window's generation change cancelling another window's shared folder thumbnail request.
- [Fixed] Inline rename boxes being covered by sticky group headers, reversed mouse-wheel pulses continuing along the old scroll direction, and hover row actions losing state across capture/reentry.
- [Fixed] Polling unchanged extension settings values triggering full-page reflows that interrupted wheel scrolling, and partial redraw clipping focus rings or control shadows.
- [Fixed] File Explorer takeover misclassifying windows during `/select` transitions, and native Explorer fallback routing for unsupported browse invocations.

### File operations

- [Improved] Better remaining-time (ETA) estimates for large and recursive file operations separating flush/commit and directory finalisation, with clearer unknown-total and finishing states, plus improved link, scope and target handling in interactive operations.
- [Fixed] Completed progress cards being hidden early by stale timers or reopened by status updates after being manually dismissed.
- [Fixed] Small-file batch ETAs being hidden by byte-rate checks, retired phase estimates reappearing after resume, and fallback delete paths inheriting native child counters.
- [Fixed] Remote clipboard paste discarding ready results on lock timeout, and preventing duplicate drops of partially executed transfers.

### Preview and 7-Zip archives

- [New] Archive browsing in Quick Look and the details pane supports thumbnails, sorting, a thumbnail size slider, and dragging files out of or into archives.
- [New] Immersive photo viewing in Quick Look (on by default): a thumbnail filmstrip, controls that fade after 2.5 s without mouse movement, an Images filter so ←/→ skip videos and other files, and a filmstrip that collapses during video playback; switch back to the classic look from the ⋯ menu (remembered).
- [New] The 7-Zip pack (1.1.0) adds archive icon style choices (including zipper-folder and colour-page styles) alongside format takeover controls on the general settings page.

### Upgrade notes

- This is an internal test build. The version keeps three parts and installs directly over 1.0.61; it is not offered through automatic updates.
- The file dialog takeover remains experimental and may not work with every program; export diagnostics from the takeover history if something goes wrong.
