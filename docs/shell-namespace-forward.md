# 系统命名空间落到 Pulse 时的处理

## 背景

文件夹接管让"打开文件夹"落到 Pulse（`Directory` / `Drive` / `Folder` 的 `shell\open`，见 `settings-persistence.md`）。但 `Folder` 是**所有**文件夹项的基类：任务栏的"文件资源管理器"按钮（Windows 11 的"主页"）、桌面上的"此电脑""回收站"图标，都会把自己的系统命名空间（`::{GUID}`）当成 `%1` 交过来，而不是一个路径。

这类输入里有 Pulse 认识的，也有没有对应视图的。之前一版把它们当普通路径打开：标签标题是那串 CLSID，正文是"无法打开 / 目录不可用"，而且这条记录还会进"最近使用"。

## 行为

`ResolveIncomingPath()`（`src/app/app_runtime.cpp`）是所有外部路径的唯一入口——命令行、单实例转发（`'PULS'`）、标签交接（`'PTBT'`）、以及 `--shot` 的起始路径都走它：

- `pulse:*` 虚拟视图原样通过；
- 真实路径按原逻辑解析成所在文件夹（带引号的路径去引号，文件路径取父目录）；
- **系统命名空间**（`fs::IsShellNamespacePath()`：`::{GUID}`、`shell:*`）查下面这张表：

| 命名空间 | Pulse 的响应 |
| --- | --- |
| `{F874310E-…}` 主页（Windows 11） | `pulse:recent`（最近使用） |
| `{679F85CB-…}` 快速访问 | 同上 |
| `{645FF040-…}` 回收站 | `pulse:recycle`（回收站） |
| 其它（此电脑、网络、控制面板…） | **不建标签**，窗口照常到前台 |

主页/快速访问映射到"最近使用"，是沿用应用自己的约定：一个"没被指向任何地方"的新窗口本来就打开最近使用（`app_main.cpp`）。回收站有同名视图，直接对应。没有对应视图的命名空间不建标签——Pulse 里"所有驱动器"的入口是侧栏，"此电脑"没有独立视图，硬开一个标签只会得到错误页。

窗口本身仍然会起来：转发路径的 `OpenFolderInNewTab()` 第一步就是 `RestoreWindow()`；新启动时如果命名空间没有视图，起始标签退回默认（会话 → 新窗口的最近使用 → `C:\`）。

## 顺带修掉的"最近使用"脏数据

命名空间曾被当作文件夹路径记录进"最近使用"，并以 `\\?\::{GUID}` 的形式落盘：

- `PlacesCatalog::RecordRecent()` 不再接受命名空间（只收真实位置）；
- `PlacesCatalog::Load()` 载入时丢掉这类遗留条目——受影响用户的"最近使用"里那两条打不开的行会自动消失，文件在下一次保存时被改写。

`fs::NormalizePath()` 也不再改写命名空间：旧行为会给 `::{GUID}` 加 `\\?\` 前缀、把 `shell:*` 折叠进当前工作目录，两者都不是路径该有的处理。

## 定向验证

只构建 `pulse` 与 `pulse_shell`（Release，带自测）；另在发布配置（仓库内 `build\`，`PULSE_WITH_SELFTEST=OFF`）上编译，并用发布版 `--test-instance --shot` 复跑同一场景，结果一致。

- `PULSE_SELFTEST_CASE=shell-namespace`（10 条）：命名空间判据（含遗留 `\\?\::{GUID}`）、主页/快速访问 → `pulse:recent`、回收站 → `pulse:recycle`、其余什么都不开、`pulse:*` 原样通过、真实文件夹（含带引号）解析成自己、命名空间不进"最近使用"、带遗留条目的 profile 载入后只剩真实条目。日志 `bench_data\selftest_1b2_last.log`。
- 截图（同一个 `::{…}` 参数）：主页 → 干净的"最近使用"标签；此电脑 → 只有一个默认标签，没有 CLSID 标签。
- 全量 `--selftest`：1236 通过 / 4 失败，失败全是 `pulse_shell.exe` 的 ops 用例（回收站删除、同卷移动、沙箱清理）——只操作真实路径、不经过本次新增的分支，且两个互不相干的沙箱位置以完全相同的方式失败，按环境问题记录（工作区在 OneDrive 同步目录）。**未做"改动前 HEAD"的对照跑**。

验证边界：映射只在自测与离屏截图里验证，**真实点一次任务栏"文件资源管理器"按钮的验收在装包后由人做**；其它命名空间（网络、控制面板）只保证不产生坏标签；`shell:*` 只按命名空间处理，不做 `shell:Startup` 之类的短名展开。
