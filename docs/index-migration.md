# 索引存储与迁移

PulseIndex 服务负责维护全盘搜索索引。可以在设置中调整索引存放位置，将索引迁移到空间更充足的磁盘。

选择磁盘根目录时，程序自动使用该磁盘下的 `Index` 文件夹。迁移完成后，服务配置切换到新位置，清理旧位置中已经为空的索引目录；非空目录保留。

服务配置位于 `%PROGRAMDATA%\Pulse\index-config.json`。升级时仍可读取旧的 `%PROGRAMDATA%\Pulse\Index\config.json`，成功保存新配置后移除旧配置文件。

迁移过程中会显示进度和结果。失败时查看界面提示；不要在迁移运行期间手动删除或移动索引文件。
