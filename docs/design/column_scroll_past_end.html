多栏：滚动到最后一项之后

场景是多栏（左右分屏、上下分屏、三栏、四宫格）之间互相拖文件，不是分栏视图。文件多、窗口矮、或者上下分屏让每栏只剩一半高度时，一栏很容易被排满：文件夹排在前面，看得见的往往全是子文件夹，松手落在哪一行就进了哪个子文件夹；想放进这一栏本身，或者对这一栏右键「新建 / 粘贴」，都找不到空白处。开启后，每一栏的列表滚到底还能再往下滚一段，最后一项下面留出空白：拖到这里就是放进这一栏的文件夹，右键就是这一栏的空白处菜单。

顺带整理多栏相关的右键命令：使用很少的「复制到目标栏 / 移动到目标栏」从菜单里拿掉，换成「在另一栏打开」，并把「复制到窗口 / 移动到窗口」扩成直接列出其他栏文件夹的「复制到 / 移动到」（第 4 节）。

1 · 交互演示

滚轮在任意一栏上滚动。单击选中，Ctrl / Shift 多选，双击文件夹进入，栏头的 ↑ 回到上级。把文件拖到另一栏：先停在底边，它会滚到最后一项；再往下移，最后一项下面的空白会跟着鼠标长出来。没放下就离开，这一栏弹回原位；放下后保留位置，新项淡入。同一个盘默认移动、跨盘默认复制，拖动时按住 Ctrl 复制、Shift 移动。右键文件或空白处可以试第 4 节的新菜单。

2 · 动画：空白跟着拖动长出

一栏（2025，已滚到最后一项）在一次拖动里的四个时刻，上排深色，下排浅色。鼠标从列表一半往下移到底边，空白从 0 长到最多半个列表高，最后一项往上让；鼠标往回移空白不缩，免得行又滑回鼠标底下、放错地方。

3 · 状态

每张图用同一套绘制代码按固定滚动位置生成，窗口都是「矮」。左列深色，右列浅色。

4 · 右键菜单：换掉「复制 / 移动到目标栏」

「复制到目标栏 / 移动到目标栏」只认一个目标栏：两栏时是另一栏，三栏、四宫格要先「设为目标栏」（ResolveTransferTarget，否则不可用）；菜单上也看不出目标到底是哪个文件夹，所以很少有人点。多栏里真正常做的是：把某个文件夹放到另一栏打开、再往里拖；或者明确地把选中项送到某一栏的文件夹。建议菜单里删掉这两行，改成下面右边的样子，快捷键不动。

6 · 行为规则

  • 对象：每一栏的文件列表（详细信息、列表、图标视图都一样，图标视图按整行瓦片计算）。单栏也生效，但收益主要在多栏，尤其是上下分屏和矮窗口。分栏视图的各列沿用同一规则。
  • 多留多少：最多半个列表高（至少 2 行），由滚轮往下滚或拖动往下推放出来，往回滚就收回。最后一项始终留在可见区（列表很矮时上限再减到只剩最后一项可见），不会出现整栏空白、像是文件夹空了的情况。
  • 只给放不下的栏：内容没有填满一栏时，下面本来就有空白，不增加滚动、不出现滚动条（图 3c 的 备份）。
  • 每栏独立：每一栏有自己的滚动位置和空白；切换布局、调整分隔条或窗口变矮时，空白按新的列表高重新限定，已经滚进空白的位置收到新上限以内。进入别的文件夹从顶部开始。
  • 键盘不进空白：End / ↓ 走到最后一项时，只滚到让它露出来为止（和现在一样）；只有滚轮和拖滚动条能滚进空白。
  • 动画：所有滚动（滚轮、拖动时自动滚、弹回）都走 Smooth 弹簧（ui_motion.h，k 380 / c 36，不回弹），跳几屏以上直接落位。
  • 拖动时空白跟着长：拖进一栏后先停在底边，自动滚到最后一项；到了末尾，鼠标在列表下半部分往下移多少，空白就长多少（平滑曲线，最多到上限）。只长不缩：鼠标往回移时行不跟着往下滑，免得目标行在鼠标下变来变去。顶边照常往上自动滚。
  • 弹回与保留：拖动经过一栏又离开、或在别处取消（Esc），这一栏弹回拖进来之前的位置；在这一栏放下，就停在当前位置，放进来的项按排序出现，淡入并从左滑入 8 dip，再有一下很淡的强调色。
  • 放到哪：空白处、文件行、栏头 = 放进这一栏的文件夹（整栏描边）；文件夹行 = 放进那个子文件夹（只描这一行）。提示沿用现有拖放规则：同盘「移动到 …」、跨盘「复制到 …」，Ctrl / Shift 改变；拖回来源栏本身提示「已在 … 中」，松手不做任何事。
  • 空白处的其他操作：右键 = 这一栏的空白处菜单（新建、粘贴、排序、在另一栏打开）；单击不改变选择、不画悬停底色；双击按现有「双击空白处」设置（返回 / 上一级，blank_pane_click.h）。
  • 关闭时：和现在完全一样，滚动范围到最后一项为止。
  • 右键菜单：「在另一栏打开」只在本标签页显示两栏以上、且对象是本地或可浏览的文件夹时出现；「复制到 / 移动到」在有其他栏或其他窗口时出现（和现在的「复制到窗口」一样，单栏单窗口的用户菜单不变长）；「移动到」在来源只读时禁用。子菜单里默认目标（两栏时的另一栏，或设了「目标栏」的那一栏）显示 Ctrl+Alt+C / Ctrl+Alt+X。
