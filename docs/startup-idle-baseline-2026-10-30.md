## 方法及实现

- 新增 `src/app/startup_perf_probe.h`，仅由 `PULSE_WITH_SELFTEST` 构建包含。主窗口最小接入，要求 `--test-instance`、独立 `PULSE_TEST_DATA_DIR`、`PULSE_TEST_P1_SCOPE=selection` 和显式报告/目标环境变量同时存在。
- 使用正常主窗口、正常消息循环、正常 NavigateTo、正常呈现。`!loading && snapshot` 且已经调用 Present 后记录列表可用时刻；不以窗口创建或后台枚举结束代替用户可见列表。
- 启动到自建两万文件目录，切换到自建空目录，再返回。随后在约5/30/60秒采样，正常 WM_CLOSE 并等待进程退出。没有修改真实文件、用户配置、剪贴板或索引数据。
- Python 脚本 `scripts/measure_startup_idle.py` 通过另一个进程的 QueryWorkingSet 统计非共享页面；探针记录主进程总工作集、私有提交和累计CPU时间。没有 EmptyWorkingSet、强制GC或堆裁剪。
- 单独构建 `build-perf-isolated`：Release、SELFTEST/TEST_HOOKS/LumaText开启、IPO关闭。没有运行完整 `--selftest`。沿用同版本运行依赖。正式发布目录与安装包未更新。
- 搜索服务由 selection fixture 禁用，因此结果是**隔离配置、关闭搜索服务的主窗口基线**，不能声称是用户真实完整配置的总占用。辅助进程/现有服务内存不计入此处。
- 连续启动复测，操作系统缓存已热；不称为冷启动。没有同期构建。未与 File Pilot 做本轮同机对照。
