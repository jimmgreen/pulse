# 大目录视图切换卡顿验证（2026-11-02）

## 复现方法

使用独立目录各含 100、10,000、50,000 个真实小文件（中英混合长文件名）。独立配置启动实际 Pulse Release 窗口，1280×800、150% 缩放；每档连续切换中图标、大图标、照片墙、列表、详细信息，共四轮。记录真实 Present 后的命令耗时、首次显示、逐帧绘制/提交与间隔。首次仅指本进程第一次切换，不是系统磁盘冷缓存。测试文件位于 bench_data/view-switch-20261102，未操作用户文件或偏好。

## 已定位原因与改动

1. 文件名折行反复为相同字符串/字体创建 DirectWrite 测量对象；增加有上限、按字体代际失效的精确测量缓存，不近似字符宽度。
2. 原动画在首帧绘制全部透明文字以预热，一次挤占数十毫秒；在文字淡入前按每帧 CPU 预算分批预热，淡入后始终绘制完整文字，模式切换重置进度。

## 定向验证

- typography_policy_test --advance-cache：直接 DirectWrite 参考值与冷/热缓存一致；字体、方向、制表位、测量代际变化及多语言逐行断点一致。通过。
- 帧数据 before.csv 为修改前基线；cache.csv 为单独缓存实验；profile.csv 为定位阶段，不是最终结果。
