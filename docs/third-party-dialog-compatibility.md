## 每个应用的操作

1. 新建一份测试文档，输入容易识别的测试文字。
2. 另存为新文件：确认是Pulse界面，文件名/类型正确，保存后应用能继续编辑。
3. 再次另存为并取消：应回到应用，不创建文件、不多弹窗口。
4. 打开刚才的测试文件：确认是Pulse界面，返回后内容正确；再打开一次并取消。
5. 报告“应用名：打开 / 保存 / 取消正常”，或指出出现原生窗口、无窗口、多窗口、操作报错中的哪一种及操作步骤。

Office的首页、最近文档页不是系统文件对话框；进入“浏览”后出现的文件选择窗口才是本轮验收对象。编码、文件类型、扩展名、覆盖确认和多选按应用实际提供的功能核对，不为表格打勾而跳过失败。
