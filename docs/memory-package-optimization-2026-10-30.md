# 内存与安装包占用优化（2026-10-30）

基线：pulse58-integrated-fixes/pulse；保留既有整合版功能与未提交修改。未进行图形后端架构改造。

## 产品改动

- Tab::SetSnapshot 解除旧 RowPresentationCache 的持有。活跃视图仍由自己的 shared_ptr 保证安全；隐藏标签无需等到再次绘制才释放旧快照。
- 缩略图条目真正淘汰时一并删除 transient_failures_ 的路径键。覆盖条目/字节上限、文件夹旧尺寸、动画旧帧；同 key 的结果替换保留重试退避。未降低缓存预算。
- 安装包按完整未压缩数据大小选择字典，上限仍64 MiB。当前约31.7 MiB输入使用32 MiB字典，不减少可引用的历史内容。

## 验证及收益口径

- 目录：修复前新增生命周期用例失败；修复后17项定向检查通过。2万条长文件名样本快照估算载荷7,074,024 B，替换后冗余持有由该值降为0。这不是进程RSS测量。
- 缩略图：修复前2万失败路径留下20,000个重试键、8,320,000 B字符串容量。修复后条目上限32时为32键/13,312 B；字节上限场景为8键/3,328 B。5项定向检查通过，包括存活项重试及两种特殊淘汰。不把失败压力负载等同于日常启动收益。
- 安装包同一固定payload（33文件）：64/32 MiB字典均为9,621,028 B压缩体积；完整解压数据及逐文件SHA-256相同。
- 使用项目原生Payload解压器、不执行安装：峰值提交内存70,451,200→36,798,464 B；峰值工作集39,022,592→39,038,976 B，基本不变。一次解压5.65/1.92秒受缓存/防病毒等影响，不宣称提速。
- Python压缩测试2项通过，覆盖9字典边界、两种发布渠道、内容/hash及低内存解码。
- 已构建pulse、pulse_thumbnail_cache_unit_test、pulse_listing_filter_perf_test、pulse_setup_p0。功能验证范围为模型/缓存及原生解压；未执行安装/卸载，不宣称安装全流程已验收。

## 限制

本轮没有取得安装包体积进一步缩小的证据；不以删除功能或运行时压缩来换体积。内存收益集中在旧目录保留、失败缩略图累积、安装解压提交额度，不承诺空闲工作集固定下降。

最终产物：dist/PulseSetup-1.0.58.exe，10,132,016 B（9.66 MiB）。最终包经原生解压，全部33文件SHA-256与当前build一致。包中主程序包含本轮两项修复。不能与磁盘上旧安装包直接比较压缩收益，旧包对应的程序内容不同。
