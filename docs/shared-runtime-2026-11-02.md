# 安装运行文件去重（2026-11-02）

## 布局

安装根目录的 `pulse.exe` 改为带原图标的小启动器，读取 `dialog-current.json` 指向经过校验的版本。所有应用与对话框运行文件位于同一 `DialogBridge/<manifest hash>/`，包括真正的 `pulse.exe`、预览、索引、Shell、提权及 DLL。根目录不再重复放置这些运行文件。

```text
Pulse/
  pulse.exe                 # 稳定启动入口
  dialog-current.json       # 当前版本指针
  DialogBridge/<hash>/
    pulse.exe               # 实际主程序
    Pulse.Index.exe
    Pulse.Preview.exe
    pulse_shell.exe
    pulse_elevated.exe
    lumatext.dll
    pdfium.dll
    ...                     # 其余生产组件、许可证、清单
```

实际安装还包含卸载器、文件归属清单、上一个版本标记等安装元数据。

使用同一个不可变版本目录，不通过硬链接、符号链接或加载可被升级覆盖的根目录 DLL 来实现去重。每个版本只存一套；仍在使用的旧版本和保留的前一版本可能暂存，不把这类保留误称为当前版本重复副本。

## 兼容性处理

- 快捷方式、自动启动、资源管理器接管、标签菜单和跳转列表使用稳定根入口。
- 主程序更新和重启定位安装根；版本内预览、Shell、AI、内容和索引辅助进程仍按同目录定位。
- 启动器保留参数、当前工作目录及标准句柄；普通 GUI 启动及时退出，标准流/命令行任务等待并传回退出码。
- 已运行的旧版本按自身验证过的目录工作，不因当前指针切换而混装依赖。
- 升级时只要求 Pulse 主窗口按原协议保存并退出，不关闭承载旧对话框的第三方应用。
- 旧根目录运行文件只按安装器的归属记录与白名单退役，不删除未知文件。
- 索引服务使用真实版本内程序作为服务映像，不能以普通启动器冒充服务程序。
