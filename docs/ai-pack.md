# AI 增强包与 MCP

AI 增强包让 Claude 等支持 [MCP（Model Context Protocol）](https://modelcontextprotocol.io/) 的 AI 应用使用 Pulse 查找和整理文件。只读和改变显示的操作直接执行；新建文件之前，Pulse 会在自己的窗口里先问你，新建的文件可以撤销。整理、移动和删除文件、打开程序等默认关闭，由你按分组打开。不安装、或者不打开开关时，Pulse 不运行任何与 AI 相关的后台程序。

## 安装和打开

1. 打开「设置 → 增强包」，在「AI 与 MCP」卡片上点「安装」。增强包（`Pulse.AI.exe`）从本版本的发布页下载，校验大小和 SHA-256 后才会使用。
2. 安装后卡片上的按钮变成「管理」。点它打开「设置 → 增强包 → AI 与 MCP」，打开「允许 AI 应用连接」。
3. 在同一页点「复制配置」，粘贴到 AI 应用的 MCP 配置里，然后重启该应用。

复制得到的配置形如：

```json
{
  "mcpServers": {
    "pulse": {
      "command": "C:\\Program Files\\Pulse\\pulse.exe",
      "args": ["--mcp-stdio"]
    }
  }
}
```

- **Claude Desktop**：合并到 `%APPDATA%\Claude\claude_desktop_config.json` 的 `mcpServers` 里。
- **Claude Code**：合并到 MCP 配置文件（例如项目里的 `.mcp.json`）的 `mcpServers` 里，或者运行 `claude mcp add pulse -- "C:\Program Files\Pulse\pulse.exe" --mcp-stdio`。
- 免安装版的 `command` 是解压目录里的 `pulse.exe`。以「复制配置」得到的路径为准。

`pulse.exe --mcp-stdio` 只是一个转发器：它启动增强包里的 MCP 服务，所有操作都交给正在运行的 Pulse 执行。Pulse 没有运行、开关没打开或增强包未安装时，AI 应用会收到明确的错误，不会自动启动或安装任何东西。

## 第一次连接

AI 应用第一次连接时，Pulse 会弹出「「Claude」想连接 Pulse」：

| 选项 | 效果 |
| --- | --- |
| 允许 | 记住，以后直接连接 |
| 只允许这次（默认） | 这次运行有效，下次再问 |
| 拒绝 | 记住，以后直接拒绝 |

两分钟内没有回答，按拒绝处理。之后可以在「AI 与 MCP」页的「应用」里改成允许、拒绝，或者移除。

## AI 应用能做什么

| 工具 | 作用 | 是否询问 |
| --- | --- | --- |
| `get_context` | 当前 Pulse 窗口的状态：各栏文件夹（按屏幕顺序）、选中的项目、暂存托盘、预览和打开的对话框 | 不询问 |
| `list_folder` | 列出文件夹内容（分页） | 不询问 |
| `search` | 按名称搜索，可以限定文件夹、类型和修改日期 | 不询问 |
| `get_properties` | 大小、日期等属性（不读取文件内容） | 不询问 |
| `reveal` | 在 Pulse 里显示并选中项目 | 不询问 |
| `create_zip` | 把项目打包成新的压缩包 | **每次询问**，可以选「始终允许这个文件夹」 |
| `find_actions` | 查找 Pulse 的动作（和菜单、快捷键、命令面板是同一张表），并告诉 AI 哪些动作你允许它用 | 不询问 |
| `run_actions` | 按顺序执行动作，最多 12 步 | 由动作所在的分组决定，见下表 |
| `undo_last` | 撤销 AI 刚才做的改动 | 只能撤销 AI 自己的、仍在撤销栈顶的改动 |
| `describe_extension_api`（开发分支） | 获取声明式增强包的公开接口与清单规范 | 不询问 |
| `validate_extension_manifest`（开发分支） | 校验 AI 提供的清单文本；不会安装或运行 | 不询问 |

使用新增开发工具需要配套更新主程序和 AI 增强包。希望让 AI 帮助制作自定义面板时，参考 [增强包 SDK 与 AI 开发流程](../sdk/native/README.md)。

### AI 应用可以做的事

`run_actions` 能用哪些动作，由「AI 与 MCP」页的「AI 应用可以做的事」决定。这里的开关对所有 AI 应用生效，但只管 AI 应用（MCP），Pulse 助手的规则不受影响。

| 分组 | 例子 | 默认 | 打开后 |
| --- | --- | --- | --- |
| 查看与界面 | 切换栏和标签页、视图、排序、选择 | 开 | 直接执行 |
| 整理 Pulse | 标签、收藏、托盘、快捷键、设置 | 关 | 直接执行，可以撤销 |
| 新建 | 新建文件夹、新建文件、打包 | 开 | **每次询问**，可以选「始终允许这个文件夹」 |
| 移动、重命名和删除 | 移动、复制、重命名、移到回收站、永久删除 | 关 | **每次**先给你看计划再询问，不能始终允许 |
| Pulse 之外的效果 | 打开程序、第三方右键菜单、Git 推送 / 拉取、弹出驱动器 | 关 | **每次询问**，不能始终允许 |
| 只能你自己做 | 退出 Pulse、解锁 BitLocker、助手的权限 | — | AI 应用永远不能做 |

AI 应用读不到文件内容。关闭删除确认、助手权限、始终允许的规则、连接和 API 密钥，AI 应用也改不了，即使打开了「整理 Pulse」。只有「新建」可以设成始终允许，而且只对你选的那个文件夹（包括子文件夹）有效。规则列在「始终允许」里，随时可以移除。

给 AI 应用开发者的详细说明（参数、错误码、撤销规则）见 [ai/mcp.md](ai/mcp.md)。

## 在 Pulse 里看到什么

- **状态栏右侧**：有应用连接时显示应用名；忙碌时显示「Claude · 搜索」，等你确认时显示「等你确认」，结束后短暂显示「完成 · N 次」。没有应用连接时不显示。点它可以把确认窗口提到前面；没有待确认的问题时，打开「AI 与 MCP」页。
- **新建之后**：提示条显示「Claude 新建了 Reports.zip」，并提供「打开」和「撤销」。撤销会把压缩包移到回收站，原文件不受影响。
- **「AI 与 MCP」页**：开关和连接状态、复制配置、应用和授权、始终允许的规则、本次运行的最近调用，以及「打开活动记录」。

## 活动记录和隐私

每次调用都会写进本机的活动记录（时间、应用、工具、结果），不记录文件内容。记录保存在 `%LOCALAPPDATA%\Pulse\ai\activity\`，可以从「打开活动记录」打开；设置保存在 `%LOCALAPPDATA%\Pulse\ai\ai.json`。Pulse 不会把文件或记录发送到任何地方；AI 应用拿到的只有你允许它调用的工具的返回结果。

## 卸载

在「AI 与 MCP」页底部点「卸载」：Pulse 先停止 MCP 服务，再删除增强包，然后回到「增强包」页。应用授权和规则保留在 `ai.json` 里，重新安装后继续有效。
