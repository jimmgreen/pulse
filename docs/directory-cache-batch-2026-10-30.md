# 大目录与标签切换优化批次（2026-10-30）

基线：pulse58-integrated-fixes/pulse（1.0.58整合版）。本批要求速度与体验优先，不降低缓存预算、图像质量或动画效果。

## 改动

- Tab::SetSnapshot释放失效的分组snapshot/spans/filter与比较派生数组，避免隐藏标签长期持有旧数据。活跃PaneViewModel仍拥有其原始shared_ptr，未变化标签继续复用缓存。
- 分组扫描每行只算一次rank，复用上一行结果；沿用原GroupCompareRanks处理类型/路径/方向等语义。新分组的rank也复用。
- SnapshotStore按真正外部分配核算wstring，避免SSO与缺省冷字段重复计费；计入冷记录对象及全部7个外部字符串（含终止符，clear后仍有capacity亦计）。24MiB/16项策略不变。
- 同路径同一不可变snapshot复用已有尺寸统计；新对象仍在UI-facing锁外遍历。更新代数、目录identity、dirty及watcher逻辑不变。

- pulse_listing_filter_perf_test --check：26项全通过，包含新9项生命周期/比较过滤/分组等价、缓存命中、折叠状态与非连续分组回退。
- pulse_snapshot_store_test --memory：7项全通过。修复前4项准确复现失败。
- pulse_snapshot_store_test：原目录变化/淘汰/dirty回归16项全通过。
- 原24MiB下两个各100k短名DirEntry的实际分配合计19,200,048B可同时命中；原先每个9,600,024B被错误计为16,600,024B，导致提前淘汰。此为合成对象/缓存测试，不是磁盘目录枚举时间。
- 大冷字段单条样本实际4,328B，旧统计2,478B；修复后准确，持续写入预算验证通过。
- 同一100k条不可变snapshot重复Update/Put共200次：101.185→0.352ms。只代表跳过重复核算的该负载，不代表一般目录加载提速倍数。
- 20k标签分组邻接计算同进程12轮交替中位：17.091→9.254ms（约45.9%减少），checksums12/12一致。实际新首次FillPaneViewModel22.315ms；1000次复用平均0.000641ms且shared_ptr不变。核心循环加速不等于整页绘制加速45.9%。

## 内存与体验边界

旧数据释放用weak_ptr证明生命周期；没有宣称日常总工作集固定减少。纠正误淘汰可能让普通目录保留更多有用缓存，从而减少重复加载，而非让所有场景RSS都变小。ResidentBytes是快照载荷，不含分配器/缓存索引管理开销。此前GIF/预览释放优化保持。

构建仅覆盖pulse与直接相关测试；没有重跑无关完整回归。最终安装包仅打包/解压校验，不执行安装。

最终安装包10,136,568B（9.67MiB），33个文件完整解压及SHA-256与当前build一致。独立配置的2万文件目录启动冒烟通过：窗口出现、响应WM_NULL、正常退出child_closed=1；该冒烟不代表内容全部绘制完成。
