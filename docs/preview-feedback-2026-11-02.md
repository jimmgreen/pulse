# 菜单与视频反馈修复

菜单撤掉本次新增阴影；三个工具栏右键入口清除悬停提示并刷新背景，避免 acrylic 带入提示文字。101 项定向检查通过，实际浅深菜单截图位于 `bench_data/menu-feedback-user-20261102/`，已人工查看。

视频修复：QuickPreviewWindow 同尺寸刷新不再重建交换链；窗口增加 WS_CLIPCHILDREN，使父窗口重绘避开 MF 视频子窗口。前一个改动后用户明确反馈测试窗口仍卡，因此没有据播放进度增长宣称完成，继续进行了实际像素采样。

000.mp4 为 H.264 1080p 30fps。独立 MF 窗口 8 秒检测到240次像素变化；完整预览未加子窗口裁剪时两次为293/303次，加裁剪的两次对照和最终产品均241次。最终样本0黑帧、0次超过100ms的间隔，最长63ms。像素变化次数不等同严格解码帧数，支持父子绘制干扰的判断，不代替用户主观流畅性确认。最初单线程1484ms间隔在独立线程采样中未复现，未当作确定根因。

证据：`bench_data/q_cadence_fixed/video-feedback.log`。

AV1：增加 opening 状态，整个系统/FFmpeg尝试链结束前不显示缺解码器卡片。提示不再无依据声称声音一定正常或安装后一定能显示。本机已有自定义 C:\ffmpeg\bin\ffmpeg.exe；无相应系统解码器且无后备播放时仍可能不能播放，不自动改用户配置或安装组件。
