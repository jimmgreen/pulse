# 声明式 UI 框架交付记录（2026-11-03）

> 历史验收记录：以下状态仅适用于各段标明的固定归档。原生 C++ UI 的当前支持范围、未完成项和阶段顺序以 [主路线图](../Pulse-增强包开放能力与AI协同实施方案-2026-11-02.md) 为准；旧 U1–U5 编号不再作为当前阶段编号。

本记录描述首轮组件树与静态数据适配的交付证据，不能作为 U1–U5 全部完成的结论。公开节点覆盖现有 `fluent_components.h` 公开绘制 Spec 的适配入口，并使用 Pulse 的 Painter、EditHost、FluentMenu、字体和滚动机制。组件映射按源码核对，有自动测试防止新增宿主 Spec 后目录静默遗漏；数量本身不是完成判据。

## 作者可用的能力

- 基础控件、图标/提示、状态提示、菜单、标签页、分段选择、滑块、侧栏分组、面板组合及状态栏。
- stack/grid、分隔拖拽、独立嵌套滚动；显示与启用状态支持声明式布尔绑定，祖先状态向下传播。
- virtualList/tree/dataTable 采用可见行绘制，不为每行建立窗口；树展开、键盘导航、表格文本排序、独立滚动及 MSAA 行访问均已接入。
- 本地动作通过 `panel.ui.actions` 原子更新已声明状态，可用于关闭提示条、改变显示或切换选中值。它们不会调用宿主能力服务；宿主命令仍独立授权。动作 ID 不得与宿主命令冲突。
- MCP、内置助手与 CLI 共享发现契约。AI 应读取 `uiComponents.schema`、`definitions`、`components` 再生成内容；本地动作需探测 schema 中的 actions，宿主副作用读取 capabilityDetails。
- 首轮 11 份模板包含完整 `ui-catalog` 和较小的 `ui-tree`；类型、Schema、原生校验、静态预览、隔离开发运行及打包入口一致。

公共字段及示例见 [UI 作者指南](extensions-ui-tree.md)，真实宿主映射见 [组件映射](extensions-ui-component-mapping.md)。嵌套菜单复用现有 FluentMenu：较深菜单按层级进入，Esc 返回上层，根层 Esc 关闭，不伪装成无限同时展开的级联窗口。

## 接口边界与验证范围

节点/数据/字符串预算是接口约束，不是未实现的占位功能；它们由 schema 和原生解析共同约束。首轮静态数据行来自清单。后续显式数据源只开放当前目录内存快照与所属受控任务，不凭显示节点取得任意文件、设备或他包任务访问权。原生句柄、COM/位图指针、内部动画进度不作为 JSON 入参；宿主适配器负责资源和输入生命周期。首轮证据尚未覆盖动态数据源、完整表单校验反馈与提交流程、三类真实参考页面，因此不能将这些 U1–U5 工作移出本次范围来宣称完成。它们正在补充，后续需独立列出实现和验证证据。第三方脚本、任意绘制和签名市场不由这份声明式 UI 合约承诺。

设备重置已通过注入真实 Compositor 恢复路径验证；高对比度测试使用宿主高对比度绘制路径，没有修改系统主题。中文编辑、原生 EditHost 和 MSAA 自动化已验证，但未声称执行所有系统输入法或第三方屏幕阅读器的人工兼容测试。

最终 SDK 解压、安装/回退、启动和实际包内类型编译的结果随发布归档放入旁附 `acceptance` 目录；归档测试后不回写，以保持摘要与验收对象一致。

## U1–U5 后续验收状态

Spec 映射完整仅证明公开绘制入口没有静默遗漏，不证明布局、数据生命周期、表单语义、可访问性和参考页面工作流全部成立。设置表单、集合浏览、任务监控必须分别验证成功、空、加载、错误、取消、重试、陈旧结果隔离和键盘反馈等相关状态。此记录的历史通过数量不得移作新增功能的验收证据。

## 2026-11-04 动态页面交付验证

本轮实现了当前目录快照分页、所属受控任务监控与取消、Unicode 字符数表单校验、输入法组合期间的提交保护，以及已验证树更新时按 ID 保持窗口和焦点。目录过滤和排序在后台处理不可变快照；游标绑定版本和查询条件。关闭面板只取消订阅，受控任务继续执行。声明式动作的校验用于本地状态及数据源操作，不自动串联任意宿主命令。

真实宿主证据位于 `bench_data/ui-reference-host-20261104-06`：设置表单 14 项 / 9 图、目录集合 40 项 / 8 图、任务监控 27 项 / 9 图、组合属性表 13 项 / 7 图。包括真实 137 文件分页、筛选/排序、取消重试、目录刷新后稳定 ID、旧游标拒绝、错误主体拒绝、授权撤销后的迟到结果丢弃、原生确认后的实际复制取消，以及关闭监控后实际复制完成。隔离夹具恢复和原文件内容检查通过。

四页均生成明暗主题 100% / 150% / 200% 及窄布局应用内截图；错误表单、实际目录行、任务取消和窄布局已人工检查图像。快照复制当前行、选择、滚动及校验错误，不重新请求数据或执行宿主命令。任务取消按钮位于列表之前。失败的首轮探针和构建日志保留，不能作为通过证据。
