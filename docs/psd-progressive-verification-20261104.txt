PSD/PSB progressive grid thumbnails -- 2026-11-04

Behavior
The embedded JPEG remains the quick first image for large documents. A
separate low-priority request decodes the merged composite and replaces the
first image. The response identifies an embedded result explicitly; a
fallback JPEG is never persisted as a successful refinement. Successful
refinement is persisted even when decoding was below the usual cache-cost
threshold. Legacy undersized disk entries also trigger refinement.

Only grid requests qualify. Direct preview, document image sessions and
hover cards retain their existing behavior. A failed refinement preserves
the first image without an immediate retry loop. Cancellation keeps the
need-to-refine state so painting the item again can resume the upgrade.

At most one refinement runs per cache; other initial thumbnail requests
remain parallel. This is a conservative I/O/scheduling bound, not a proven
optimal concurrency number for every machine. One/two-lane pools can still
wait for the current bounded decode. It is not evidence establishing the
cause of a particular user's UI stall.

PSD/PSB grid thumbnails now request the actual default-application icon.
After resolution confirms no icon is available, a PSD/PSB format chip is
shown instead. A pending lookup is not treated as missing. Ordinary photo
badge policy is unchanged.

Diagnostics
psd_refinement records a path hash, source/request/result edges, elapsed
time and success/embedded-fallback/decode-error/cancelled/stale outcome.
It does not record the plaintext file path. The embedded-fallback outcome
does not distinguish every internal composite decoder failure reason.

Limits
The reporting user's original PSD was unavailable; generated fixtures were
requested by the user. No computer-use automation was used. The new format
chip has layout-bound checks but has not received a production UI screenshot
review. This change does not promise every PSD can provide a full composite:
unsupported, missing, corrupt or resource-limited composites retain the
embedded first image.
