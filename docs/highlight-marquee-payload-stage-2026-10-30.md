# 搜索高亮、框选与预览载荷优化

基线：pulse58-integrated-fixes/pulse，58整合版，2026-10-30。保留原有未提交改动。本报告只记本轮新增内容。

## 搜索高亮

Table/Tree/Markdown 不再每次重绘复制全部匹配为另一份数组；同步借用有序匹配位置，并只遍历与当前文本段相交的匹配。旧显式高亮列表仍兼容，包括不同长度和交叠项。借用不能跨绘制生命周期保存。

10万匹配、10帧、5组旧新配对的中位数：

|准备/遍历模型|旧 ms|新 ms|
|---|---:|---:|
|表格/树|7.6377|0.0210|
|Markdown 40段|44.3373|0.0312|

临时分配10→0次，累计请求12,000,390→0字节；Markdown访问4,000万→4,400个匹配。不是整体绘制耗时、帧率或常驻内存测量。原始样本和复现命令在 `build/search_highlight_before/`。

验证：5,000组随机区间及边界通过；真实三种视图 DWrite/WARP 全图像素对照通过，覆盖浅/深色×100%/150%、当前项/无当前项、空匹配、跨段匹配与 Markdown 文本选择。纯文本 DrawTextPreview 的全量高亮扫描尚未改动。

## 框选

保留原可见候选收集和过滤。首次建立选择状态后，仅对前后框选范围的差量更新集合；结果不变时不增加选择版本，避免无意义地使汇总缓存失效。保留 Ctrl 反选、Shift 并集、普通替换、全选压缩表示和 Esc 恢复。窗格、标签、快照、树、视图代际或外部选择版本变化后终止旧手势，避免覆盖新目录。

10万基础选择、40个命中、200次更新，3组中位数（包含首次初始化）：

|模式|旧 ms|新 ms|
|---|---:|---:|
|Shift|3940.472|19.996|
|Ctrl|4298.211|18.725|

Shift分配20,006,502→100,150次，累计请求480,156,048→4,501,007字节。这些是集合处理和累计分配，不是应用整体速度或同时驻留量。普通替换选择的短时样本波动，不声称稳定提速。完整样本 `build/marquee_incremental_perf.log`，前源码 `build/marquee_incremental_before/`。

手势结束或取消时：临时 vector capacity>1024、集合 bucket_count>2048 则释放，否则清空复用。只在结束时执行，不改变每帧路径。

验证：57,600帧随机旧算法对照、各模式扩张/缩小/反向/空/全选、Reset复用及owner身份检查通过。新增10万容量释放、小容量保留检查通过。尚未进行真实鼠标交互验证，不能将纯逻辑检查称为完整UI验收。

## 预览载荷

ThumbnailCache::Draw 保留旧 wstring 输出，增加可选不可变共享正文输出。首次共享命中移动原缓冲，后续仅复制持有权；QuickPreview 只在当前绘制持有正文，不增加长期缓存。空正文不创建共享对象。待加载、失败、取消、无效请求先清空输出，避免显示上个文件内容。cache cost保持原有正文计费。

实际缓存 Draw 命中路径、100次调用、10组交替样本中位数：

|正文大小|旧兼容复制路径 ms|共享输出 ms|
|---|---:|---:|
|64 KiB|0.2355|0.0416|
|8 MiB|464.9662|0.04315|

对照是同一cache的旧兼容输出与新共享输出，不是两个不同版本exe。每100次正文复制长度按字符数推算6,553,600/838,860,800→0字节；不是分配器测量，也不是私有常驻减少量。该结果排除解析与整窗绘制。原样本、源码before、独立编译命令：`build/preview_payload_before/`。

22项实际缓存验证通过：promotion正文/计费、warm复用、旧新接口并存、切路径/切sheet待加载清空、淘汰后持有者有效、过时代际拒绝、替换不修改旧引用、取消/无效/失败、六类文本内容、空Text/Bitmap不分配。
