# 索引迁移与可靠性审查

## 使用体验

在设置中选择新索引目录后，迁移在后台执行。设置显示迁移状态并禁止重复提交；文件浏览仍可使用，索引搜索会在服务停止和恢复期间等待。迁移需要机器级权限，因此系统可能要求一次管理员授权。

流程为：串行获取配置锁 → 等待旧服务停止并释放文件 → 检查目标及空间 → 复制到临时文件 → 落盘、校验并发布 → 保存新配置 → 启动服务并观察稳定性 → 清理旧索引。成功时不弹确认框，界面更新实际使用的位置。遇到占用会有限重试；相同且已验证的目标副本可复用。

失败时弹出原因并在设置中保留错误；启动失败尽量恢复旧配置和服务。复制、切换未成功时保留原索引。清理失败明确提示“新位置可用，但旧文件未完全清理”，不会回滚已经可用的新索引。

只处理已知的基础索引、分片、增量日志和清单，清理前再次核对源文件。保留配置、日志、用户文件和用户选择的根文件夹；拒绝互相包含的目录、磁盘根目录和链接目录。`C:\ProgramData\Pulse` 仍保留服务配置与日志。

## 审查中修复的问题

| 问题 | 影响 | 修复 |
|---|---|---|
| 只改路径并重建，没有真正迁移数据 | 旧索引占空间，离线卷缓存不能随位置保留 | 校验复制后切换，成功后清理旧文件 |
| 两分钟等待超时，但提权进程仍运行 | 界面误报失败，用户可能重复操作 | 后台等待真实完成，机器级配置锁避免并发修改 |
| 服务刚进入 RUNNING 即认为成功 | 可能漏掉随后启动崩溃或目录无写权限 | 启动时验证服务身份可写目录，检查服务稳定性，失败恢复 |
| 增量日志部分写入失败后继续追加 | 重试可产生重复或残缺记录 | 从已提交边界重写，写入及落盘成功前保留待写数据 |
| 索引保存失败仍显示“实时更新” | 用户不知道索引无法持久化 | 保存及增量写入失败显示错误状态 |
| 提权命令没有正确转义末尾反斜杠 | 部分路径被错误解析 | 统一 Windows 参数引用，增加解析往返测试 |
| 安装器忽略索引命令退出码 | 安装结束却未应用所选路径 | 检查安装及迁移命令结果，失败提示并保留可用配置 |

上一轮已修复服务重连误启动用户索引、活动目录与配置目录混用、升级重置路径及中文配置解码问题。

## 验证

- 17 套候选版回归通过，包含迁移、索引引擎、主机压力、控制器、操作、预览、搜索、更新及自测。
- 迁移测试覆盖复制校验、原文件保留、提交清理、已有副本复用、目标冲突、锁定文件重试、源文件变化、中文路径、目录边界及回滚。
- 利用文件区域锁触发第二个写入块失败，验证增量日志重试后长度准确，没有重复追加。
- 设置控制器测试覆盖迁移状态及失败后实际路径刷新。
- 隐藏窗口截图覆盖迁移中的窄设置窗口、新旧能力路径和明暗主题。测试没有控制桌面。

结果见 `bench_data/win81-tests/results.json`、`bench_data/win81-visuals/results.json`。本次审查集中在索引迁移、持久化、服务生命周期和安装升级，不代表证明整个软件不存在其他缺陷。

## 尚需实际环境复验

没有改变用户已安装的服务或真实索引目录。请安装后检查实际 SCM 停止/启动、跨磁盘迁移、管理员授权、权限受限或磁盘空间不足时的提示，以及迁移后旧索引是否清理、文件搜索是否更新。Windows 8.1 继续标记为兼容候选版。

异常断电或强制终止不属于正常失败返回，可能留下已复制的文件；本版优先保留可用数据，不会在未校验时删除源索引。不同内容的目标索引会被拒绝覆盖。
