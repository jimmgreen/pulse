# Pulse 1.0.2 Windows 8.1 x64 兼容候选版

交付日期：2026-09-09。尚未通过真实 Windows 8.1 验证，不代表已经正式支持该系统。不支持 Windows 8.0、32 位 Windows 或 Windows RT。

## 安装包

- 文件：`dist/PulseSetup-1.0.2-win81-candidate-r6.exe`，4,089,866 字节（不带修订后缀的候选包亦已更新为相同内容）。
- SHA256：`4250CEB6EA5C1EFB9DBF5CDD727453CC6E3AE534D2A9E4FC27D5657CC9263AD2`。
- 同一候选安装包面向 Windows 8.1/10/11 x64；沿用 AppId 和配置位置，静默升级保留用户数据。
- 构建：VS 2022 v143 14.44 工具集、Release、静态 C/C++ 运行库。运行 `build_win81_installer.bat` 重建，或在完成候选构建后加 `/skipbuild` 打包并审计导入依赖。

## 已完成的行为

候选版 r6：详细信息列表增加可开始框选的左右留白；通用设置增加“显示隐藏文件”（默认关闭），同时处理范围选择、全选、反选、文件监视更新与可见项目计数。安装器补齐 32/64 位和用户/机器级旧安装记录识别。17 套回归、最终 589 项自测及 16 个隐藏渲染/启动检查通过；安装覆盖路径尚未通过实际升级验证。详见 `docs/list-visibility-upgrade-r6.md`。

候选版 r5：标签和提示卡片的指示条直接按圆角几何蒙版裁剪；修复裁剪辅助函数的工厂引用泄漏。参考 LUMENUI 的标题/正文层级，更新 Fluent 提示卡片的图标底色、留白、边框及轻阴影。迁移失败改用不抢焦点的窗口内 Toast，支持关闭反馈、Esc 关闭和防点击穿透；普通提示支持自动收起及悬停暂停。未改动 LUMENUI。17 套回归及 574 项自测通过；实际桌面交互与 Windows 8.1 真机仍需复验。

r5 的 11 个隐藏渲染/启动用例通过。损坏可选文字引擎曾触发加载器等待，已按 [Windows 线程错误模式](https://learn.microsoft.com/en-us/windows/win32/api/errhandlingapi/nf-errhandlingapi-setthreaderrormode) 仅在受控加载期间关闭系统错误框，并恢复原模式；缺失及损坏 DLL 的降级启动复验通过。

候选版 r4 将索引路径切换升级为后台复制、校验、服务切换及旧索引清理流程；成功不弹窗，失败说明原因并尽量恢复原服务。文件浏览继续可用，索引搜索在服务切换期间等待。ProgramData 中的配置与日志仍保留。新增部分写入失败重试保护、参数引用修复及安装器错误检查。详见 `docs/index-migration-review.md`。

此前 r3 修复了活动目录与配置目录混用、重连误启动另一份用户索引、升级重置路径和 UTF-8 中文路径读取问题。

路径修复验证：候选版 17 套回归及 9 个渲染/启动用例通过；常规版迁移、索引引擎、控制器测试通过；两个 Release 安装包编译通过。未操作用户已安装服务，真实 SCM 停止/启动、安装升级与实际磁盘路径切换仍需手动复验。

候选版 r2 修复真实 Windows 8.1 反馈的图形初始化兼容遗漏：旧系统交换链改用 FLIP_SEQUENTIAL，现代系统仍优先 FLIP_DISCARD；创建失败时使用兼容的备用路径。参考 [DXGI_SWAP_EFFECT 支持范围](https://learn.microsoft.com/en-us/windows/win32/api/dxgi/ne-dxgi-dxgi_swap_effect)。初始化错误现在显示具体步骤和 HRESULT，记录至 `%LOCALAPPDATA%\Pulse\pulse_graphics.log`。r2 已重新通过 8 个渲染/启动用例、相关 5 套回归及发布导入检查，真实 Windows 8.1 启动仍待复验。

鼠标侧键支持当前活动标签页后退（XBUTTON1）和前进（XBUTTON2），没有对应历史时保持原地；兼容鼠标驱动发送的浏览器前进/后退命令。使用 Windows 的 [WM_APPCOMMAND 消息](https://learn.microsoft.com/zh-cn/windows/win32/inputdev/wm-appcommand) 接入既有导航，避免按下和松开重复触发。

目录右键、全目录多选和普通目录空白处提供固定/取消固定命令。固定目录依次追加在快速访问内，与桌面、下载同级。侧栏固定项支持取消固定；文件、混合选择、回收站等虚拟位置不提供固定命令。固定数据独立保存，不同步资源管理器，也不影响收藏与工作区。

路径规范化去重，支持磁盘根目录与 UNC；应用内移动、重命名同步固定路径。离线入口保留，菜单构建不探测网络目录。新增命令接入菜单配置及中英文资源。

DPI 接口统一动态检测；基础绘制使用旧系统可用接口，新版文字和 SVG 能力按需启用。旧系统使用路径图标及主题纯色背景，设置明确禁用不可用材质。LumaText 受控延迟加载，旧系统或 DLL 缺失、损坏时使用 DirectWrite。未修改工作区外的 LumaText 源码。

## Windows 8.1 手动检查清单

请在 Windows 8.1 x64 上逐项记录通过/失败；涉及删除的项目使用临时测试文件。

- [ ] 安装：完成安装；分别检查不启用/启用索引服务的启动结果，无入口点缺失或 DLL 加载错误。
- [ ] 升级：安装前设置主题、收藏和固定目录，覆盖安装后确认保留；旧配置未包含固定字段时正常打开。
- [ ] 快速访问：目录右键、当前目录空白处固定；重复固定不增加；批量全目录可用，文件及混合选择无命令；侧栏同级且顺序稳定。
- [ ] 固定状态：重启仍保留；取消固定不改变收藏/工作区；应用内重命名及移动目录后入口更新。
- [ ] 网络：固定可用 UNC；网络断开后入口仍在，点击有导航错误反馈，右键不因网络探测卡住；恢复网络后可打开。
- [ ] 文件操作：创建、复制、移动、重命名、删除至回收站、撤销；测试取消长操作、空目录、无权限目录和长路径。
- [ ] 浏览：多标签、快速切换目录、排序、空白与条目右键菜单均可用，取消菜单无误操作。
- [ ] 鼠标侧键：连续打开三个目录，后退/前进每次只跳一步；没有历史时不跳转；在输入框上、切换标签或分栏后仍控制当前活动标签页。
- [ ] 搜索：文件名与内容搜索正常；启用服务后全盘索引工作，重启后恢复；服务停用时反馈合理。
- [ ] 预览：文字、图片、缩略图和可用的系统预览提供程序正常；快速切换及取消后不显示旧结果。
- [ ] 外观：明暗主题、窄窗口、100%/150%/200% 缩放、可用时多屏切换；菜单、颜色选择器与预览无裁切，图标无方框。旧系统不可用材质显示禁用提示并使用纯色。
- [ ] 更新：检查更新和候选包覆盖升级均正常；不向尚未正式支持的系统发布不兼容的更新清单。
- [ ] 卸载：程序和 PulseIndex 服务移除；按需要选择是否清理用户数据。当前交互卸载默认勾选清理，若要保留配置须取消勾选。

反馈请包含系统版本、失败步骤、截图和 `%LOCALAPPDATA%\Pulse` 下相关日志（如 `pulse_crash.log`、`pulse_shell_host.log`）。完成真机验证并修复反馈后，再确认正式支持。
