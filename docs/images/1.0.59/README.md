# README screenshot set

Captured on 2026-11-09 for the Chinese and English project homepages.

- These are captures of real Pulse windows, not interface mockups or composited UI.
- Capture used the existing self-test-enabled development executable with the recent UI fixes. Its embedded version was still **1.0.58**; the repository's release metadata had been advanced to **1.0.59**. No new installer or release build was produced for this documentation-only update.
- Files, artwork and profiles were prepared specifically for these screenshots. The landscape illustrations are original procedural demonstration artwork, not photographs or user files.
- A temporary drive mapping kept personal directory paths out of the interface. It was removed after capture; no system integration settings were changed.
- The assistant screenshot uses Pulse's local demo mode and a prepared answer. It makes no model API request and performs no file rename. Both homepages disclose this next to the image.
- The batch-renaming screenshot shows a proposed plan before execution. The directory comparison shows actual metadata differences between two demonstration folders, not recursive content verification.
- Capture helpers, profiles, original demo files and intermediate shots remain in the ignored local `bench_data/readme-refresh-20261109` directory. Only the selected screenshots are published here.
