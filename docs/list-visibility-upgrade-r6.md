# 列表与安装目录改进（r6）

- 详细信息视图在左侧留出 8 DIP，右侧在滚动条之前留出 8 DIP。文字、列头、行命中和框选使用一致的几何边界；边距随 DPI 缩放。
- 设置 → 通用 → 显示隐藏文件，默认关闭，旧配置也按关闭读取。只按 FILE_ATTRIBUTE_HIDDEN 过滤，不隐藏普通点号文件；回收站不屏蔽 Windows 隐藏的回收载荷。完整目录快照保留，切换无需重新枚举网络目录。
- 全选、反选、范围选择、源索引/显示索引转换和文件监视更新均考虑隐藏项；开关切换会清除选择，避免继续操作已不可见的文件。
- 安装器继续使用相同 AppId；补齐 HKLM/HKCU 的 64/32 位卸载记录识别。默认程序目录与旧版本卸载使用同一记录，优先读取 Inno Setup: App Path，再读取 InstallLocation。显式 /DIR 和向导中的用户选择仍有效。

本机只读查询得到的安装记录指向 C:\Program Files\Pulse，无法还原用户此前安装时的目录选择。缺少原安装日志，因此不声称已经复现该次安装问题。不同账户、丢失注册记录或手动移动过程序目录仍需具体日志核对。

## 手动复验

不自动安装、卸载或控制用户桌面。请在测试环境验证：

1. 从左右留白开始框选，滚动后、100%/150%/200% 缩放下仍可使用；滚动条可正常拖动。
2. 关闭/开启隐藏文件，在多个标签页中生效；重启恢复设置。对含 desktop.ini、隐藏目录及普通点号文件的目录验证全选、反选和 Shift 选择。
3. 先安装到自定义路径，再运行新版，默认程序目录应沿用旧路径；确认快捷方式和索引服务指向新程序。分别验证普通版、兼容候选版以及旧 32 位注册记录升级。主动指定新程序目录时应尊重选择。
4. 升级保留配置和索引设置，真实 Windows 8.1 的安装/启动/卸载仍按候选版清单复验。

## 构建依赖检查

常规工具链仅安装中文资源，VSLANG=1033 会回退到中文，不能单独保证依赖识别。构建脚本统一配置与编译的控制台编码，避免 Ninja 未识别 /showIncludes 后混入旧对象。相关机制参见 [CMake 的 MSVC 输出编码处理](https://gitlab.kitware.com/cmake/cmake/-/merge_requests/5089)。

新增 `build_release.bat /clean`，用于清除旧编译器检测缓存并完整重编译（会重新初始化 CMake 构建选项；自定义签名/更新等选项需重新传入）。已对这次常规包执行干净构建，并通过实际修改头文件时间戳验证控制器、设置控制器及配置模块自动重编译；随后恢复头文件时间戳，未改变内容。
