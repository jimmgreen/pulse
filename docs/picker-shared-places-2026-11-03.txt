Pulse open/save dialog shared places — 2026-11-03

Scope
- Expose main Pulse workspaces, starred files/folders and starred folder groups.
- Drag selected dialog entries to the Starred section to add references, or to a
  starred group to add folders. Duplicate additions do not toggle favorites off.
- Drag to a workspace or starred directory using the existing copy/move policy
  and operation/conflict UI. No filesystem probing is added to UI hit testing.
- Favorite file clicks navigate to its parent and select it without accepting.
- Dragging from Save retains the previously typed output filename. Escape cancels.
- Persist collapse state for the two new sections.
- Hidden first-frame preparation accepts DXGI_STATUS_OCCLUDED after successful
  drawing. The visible takeover readiness check still requires a presented frame.

Shared data
- Keep v1 mapping compatible; v2 carries bounded shared catalogs and main host PID.
- Mutations go to the main catalog, with asynchronous coalesced persistence.
- If the main process is unavailable, saved catalogs are loaded read-only on a
  worker. Navigation and directory copy/move remain available; adding favorites
  reports that Pulse must be opened. The dialog never starts a second writer.
- Current protocol bounds: 384 shared rows, paths shorter than 1024 wchar_t,
  labels/group IDs shorter than 128 wchar_t, at most 64 favorites per drop.
