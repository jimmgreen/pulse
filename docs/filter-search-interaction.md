# 栏内过滤与搜索命中提示

- 过滤和搜索结果的文件名、文件夹名用黄色/琥珀色背景突出匹配文字，保留原有名称布局、标签点和最近变化标记。重复匹配全部显示，省略号不参与高亮。
- 沿用已有匹配语义：过滤中的名称短语、通配符字面部分，以及搜索中的正向名称条件。类型、日期、大小、路径、内容和否定条件不会被当作名称关键词。仅处理可见项目，每个窗格绘制时解析一次查询。
- 点击过滤框之外结束编辑并取消待执行的焦点请求。已有过滤内容继续生效且框保持展开，不抢回焦点；空内容失焦时收回。
- 非空过滤框右侧显示清除按钮。点击清空过滤、恢复目录中的文件和文件夹、回到列表顶部，并将过滤框收回图标。输入文字和按钮不共享命中区域，窄框为两者保留空间。
- 展开和收回使用 140 毫秒的缓出动画，没有渐近收尾。原有搜索清除和关闭行为保持不变。
- 名称列过窄时静态隐藏行内快捷按钮，以保留名称和标签；选择不依赖鼠标悬停，文件操作仍能从右键菜单进入。窗格标题放不下时显示省略号。

## 定向验证入口

仅构建 `pulse` 及其必要依赖，通过 `PULSE_SELFTEST_CASE` 选择 `filter-controls` 或 `filter-search-ui` 后运行 `pulse.exe --selftest`，不运行全部历史测试。

交互检查日志：`bench_data/filter-controls-results.log`。匹配、布局与实际渲染日志及截图：`bench_data/name-highlight`。隐藏窗口测试不会修改用户文件或剪贴板；渲染截图为受控数据，不代表安装版现场操作。

本轮结果：`filter-controls` 16 项通过；`filter-search-ui` 67 项通过（包含 43 项匹配/布局断言和 24 张截图生成）。实际查看过滤、搜索、图标、窄栏的浅深主题及 100%/150%/200% 代表截图。首轮截图发现窄栏名称被快捷按钮挤掉，修正静态空间分配后复查通过；随后修正整段文字与省略号字距的测量误差，避免二次拟合多截断字符。未运行全量历史测试。

安装包：`dist/PulseSetup-1.0.11-filter-search-fix.exe`，包含配套索引程序及之前的回收站删除修复。未执行真实覆盖安装、现场输入法操作或人工连续动画观感验收；140 毫秒时限和点击流程通过受控测试验证。

## 过滤后列表空白修复

`1#` 会按名称字面匹配，不是标签条件。输入过滤文字时若仍保留旧的纵向/横向滚动位置，少量结果可能处于可见区域之外。过滤内容改变及清除时现同时重置两方向位置、纵向动画目标并取消滚动动画；重复的相同内容通知不打断用户浏览结果。

用 `1#2#小学教学楼结构` 和旧滚动位置构造的定向回归：修复前匹配检查通过、结果可见检查失败；修复后 `filter-controls` 19 项全部通过。日志保存于 `bench_data/filter-hash-before.log` 和 `bench_data/filter-controls-results.log`。仅构建受影响的 `pulse`，未重跑无关匹配、渲染和历史测试。

最新安装包：`dist/PulseSetup-1.0.11-filter-scroll-fix.exe`。本轮未实际覆盖安装用户环境。
