# Project File Capsules (`com.pulse.project-capsules`)

Pulse Native SDK plugin that highlights design, 3D, CAD, and video project source files with inline colored extension capsules across all file views (icon/thumbnail grids, details, list, tiles, and content) via `pulse.extcapsules` — with zero thumbnail occlusion.

## Default Style

- Dotted lowercase labels (`.psd`, `.ai`, `.prproj`, `.c4d`, `.blend`, ...)
- High-contrast dark brand capsules with bright brand text in both light and dark themes
- Configurable in **Settings > Extensions > Project File Capsules**:
  - Enable / disable capsules
  - Include optional semi-project formats (`.pdf` / `.svg`, off by default)
  - Switch between high-contrast dark capsules and theme-adaptive light/dark palettes
  - Switch between dotted lowercase (`.psd`) and uppercase (`PSD`) labels
