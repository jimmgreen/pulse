桌面增强包：Pulse 右键、一键整理、磁贴

装上以后，桌面右键换成 Pulse 的菜单。散落的文件按规则收进分组，常用文件夹、磁盘、回收站变成会动的磁贴。分组、磁贴、菜单和任务栏跟 Pulse 一样，可以选 亚克力 / Mica / Mica Alt / 无。分组只改显示位置，文件仍在桌面文件夹里，关掉增强包就回到原来的桌面。

右键空白 / 文件 / 分组标题 / 磁贴 拖文件进别的分组、空白处、回收站磁贴；拖分组标题移动，右下角改宽度；拖磁贴换位置 单击磁贴或双击文件夹：Pulse 从那里展开 空格 快速查看 · F2 重命名 · Delete · Ctrl+A · Ctrl+Z
