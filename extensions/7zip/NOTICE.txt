Pulse 7-Zip extension
=====================

This extension uses 7-Zip 26.00 (7z.dll), Copyright (C) Igor Pavlov.
7-Zip is licensed under the GNU LGPL with BSD components and the unRAR
restriction; see License.txt in this package.
Official source: https://github.com/ip7z/7zip/tree/26.00
Downloads and corresponding source: https://www.7-zip.org/download.html

The unRAR code in 7z.dll may be used only to extract RAR archives; it must not
be used to re-create the RAR compression algorithm.

The extension's own code (pulse_7zip.dll) is part of Pulse:
https://github.com/jimmgreen/pulse/tree/main/extensions/7zip
